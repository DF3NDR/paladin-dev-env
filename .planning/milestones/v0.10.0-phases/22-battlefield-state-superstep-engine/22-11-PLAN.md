<objective>
Bridge the legacy string-based execution patterns into the typed engine without touching them, and
prove the bridge is lossless with byte-for-byte golden equivalence tests. Then close the phase's
coverage gate.

Purpose: X-03 makes backward compatibility non-negotiable and ENG-FR-20 keeps the legacy services
untouched. The only way "the bridge reproduces today's data flow" is a claim rather than a hope is a
test that runs both paths over the same mock port and compares their output byte for byte.

Output: `from_formation`, `from_phalanx`, `from_campaign`, the golden test suite, and a measured
coverage figure for the phase's new modules.
</objective>

    Create `tests/integration/golden_bridge_equivalence_test.rs` and register it in the root

    For each of the three patterns, construct the fixture once and run it twice over the SAME
    configured mock port outputs: once through the legacy execution service and once through
    `WarEngine` over the bridged `WarGraph` with an in-memory Waypoint backend. Compare with

    exact whitespace.

    answer for the wrong reason, and a later change to either path would then diverge silently.
