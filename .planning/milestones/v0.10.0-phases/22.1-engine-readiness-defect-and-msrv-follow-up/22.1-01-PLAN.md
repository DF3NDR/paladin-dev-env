<objective>
Fix BUG-03 — the cycle-bootstrap starvation defect in `Frontier`'s readiness rule — test-first,
and register the defect in the program's three `.project/` register files.

Purpose: `Frontier::is_ready` requires EVERY incoming edge to be resolved before a node is
scheduled. A back-edge into a cycle stays `Pending` because its source can only run *after* the
target, and `propagate_dead` never marks that source dead. The node never takes a first turn and
the run reports `Completed` anyway — the same truthful-outcome lie BUG-02 fixed by a different
mechanism (D-01).

Output: a starvation-release fallback pass in `compute_next_vanguard`, two green reproductions
(the previously-`#[ignore]`d self-loop case and a new general-cycle case), and BUG-03 /
ENG-FR-06a registered.
</objective>
