## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored Waypoint -> `resume` | A persisted `GraphFingerprint` crosses back into the process and is compared against the live graph. An under-covering fingerprint lets a materially different graph pass as the same one. |
| `WarGraph` -> canonical bytes -> blake3 | The byte-canonicalization boundary; any instability here (e.g. `Debug` output, HashMap order) silently invalidates or falsely validates stored threads. |
| in-process only | No network, filesystem, credential or external-input surface is touched by this plan. |
