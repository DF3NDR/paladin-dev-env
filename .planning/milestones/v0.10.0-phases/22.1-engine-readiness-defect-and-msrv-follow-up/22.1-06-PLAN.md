<objective>
Fix BUG-04 — `WarEngine::resume_with_options` rebuilds the `Frontier` from scratch, discarding every
per-edge resolution recorded before the crash — test-first, persist the frontier on the `Waypoint`,
prove it across all three `WaypointPort` backends, and register the defect as BUG-04 / ENG-FR-12a.

Purpose: `resume_with_options` hands `superstep::run` the Waypoint's Battlefield, Vanguard and
`visit_counts`, and `run` calls `Frontier::new(graph)` — every edge `Pending`, `last_executed`
empty. A pre-crash fired edge into a join node that was not yet ready is never seen again, so the
resumed run can complete without a node the uninterrupted run executes. ENG-04's promise ("final
state equals the uninterrupted control run, zero re-execution") holds today only for shapes without
such a pending join across the crash point (D-21).

Output: a serializable `FrontierSnapshot` on `Waypoint` (additive, `#[serde(default)]`), seeded into
the `Frontier` on resume and written on every Waypoint the loop produces; two contract-suite cases
proving it survives all three backends and that pre-BUG-04 payloads still load; BUG-04 / ENG-FR-12a
registered; and the `resume_with_options` rustdoc stating the restored-frontier guarantee.
</objective>
