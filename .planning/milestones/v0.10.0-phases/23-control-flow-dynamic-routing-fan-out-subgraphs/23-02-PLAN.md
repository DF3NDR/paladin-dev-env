<assumption_delta_decision>
**Signals fired:** `optional` ("optionally route by LLM evaluation"), `chosen` ("configurable
`DirectiveParser`", "custom"), `pluralization` ("fallback").

**The identity question:** with `NextStep` making routing node-authored, has the primary noun for
"what decides which node runs next" moved from the static `EdgeSpec` to the node's returned
`Directive`?

**Decision: `add-alongside`.** `EdgeSpec` remains the primary routing authority — `NextStep::Edges`
is the default and preserves PRD-01 semantics exactly, so every graph that predates this phase
routes unchanged. `Directive` is a second, node-authored authority layered on top.

**Rationale:** promoting `Directive` to primary would make static edges a special case of dynamic
routing and would force every existing graph shape through the new path; keeping `Edges` as the
default is what makes CF-02 additive and keeps the E2E-1 golden byte-identical.

**Accepted debt:** two routing authorities now coexist, and their interaction is a real invariant
rather than a free composition. It is reconciled by exactly one rule — D-08c: a non-`Edges`
`NextStep` resolves the emitting node's static outgoing edges `NotFiring` for that superstep. That
rule is the seam a future defect would appear at; it is covered by a named test in Task 1 rather
than left implicit.

**Suggested invariant test:** for every `NextStep` variant, the emitting node's static outgoing
edges end the superstep in exactly one of `Fired` or `NotFiring` — never `Pending` — so no
`NextStep` addition can silently strand a downstream join.
</assumption_delta_decision>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| node implementation -> scheduler | A `StateNode` now returns routing instructions, not just data. `Goto` targets, `Muster` task lists and `End` are runtime-produced values the scheduler must validate before acting on. |
| caller -> `RunOutcome` / `WaypointStatus` | The completion verdict is the trust surface; a `Completed` that hides an un-run node is the boundary violation 22.1 closed and this plan must not reopen. |
