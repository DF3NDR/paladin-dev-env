<objective>
Land Muster dynamic fan-out: a graph-level worker-template marker set, runtime-N worker tasks
dispatched concurrently in one superstep with isolated payloads, deterministic `task_key`-ordered
aggregation, and every malformed-muster case rejected before a single task starts.

Purpose: Muster is the map half of map-reduce and the heaviest single change in this phase — it is
the only cluster that adds new per-superstep scheduling semantics. Getting the "validate before
dispatch" ordering and the deterministic merge order right is what makes program scenario E2E-3
reproducible.

Output: `add_worker_template` and its validation clauses, `NextStep::Muster` dispatch through the
existing vanguard machinery, the `muster.` template namespace, `EngineLimits::max_muster_tasks`,
and deferred aggregation that runs exactly once.
</objective>
