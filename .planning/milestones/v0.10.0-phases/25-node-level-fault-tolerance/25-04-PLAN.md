<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine -> `NodeCachePort` -> Redis | A `StateDelta` produced in-process is written to and read back from an external store |
| `NodeCacheKey` -> Redis keyspace | A composed key string addresses a shared keyspace that may host other Paladin subsystems |
| operator config -> `NodeCacheConfig.redis_password` | A credential enters process configuration and must not reach a log or a `Debug` rendering |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
