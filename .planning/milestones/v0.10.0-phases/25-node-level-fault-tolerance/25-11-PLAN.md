<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mustered task handler -> aggregation | A per-task handler's return value becomes part of a fan-out result set other nodes read |
| handler-raised `ParleyRequest` -> persisted Waypoint | Handler-authored prompt and payload become durable, human-facing content |
| compensation cycle -> scheduling budget | Two nodes routing to each other could consume unbounded supersteps |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-51 | Tampering | a mustered task escaping its aggregation | high | mitigate | `Route` on a worker template is a validation error and a `Custom` handler must return a delta-only `Directive`, else a typed runtime error naming node and task key (D-22); aggregation semantics for a routed task are undefined and the case is rejected rather than guessed |
| T-25-52 | Denial of Service | an unbounded compensation cycle | high | mitigate | `max_node_visits` bounds handler-routed visits (plan 25-10) and `compensation_loop_terminates_at_the_visit_limit` proves it end to end under a timeout guard (FT-FR-15) |
| T-25-53 | Information Disclosure | a handler-authored `ParleyRequest` persisted verbatim | medium | mitigate | The request is author-supplied content persisted into the Waypoint exactly as a node-raised parley already is (Phase 24 T-24-02); no engine code copies a credential or a provider body into it, and the raw-content warning in plan 25-14's guide covers it (D-34) |
| T-25-54 | Tampering | a second, non-durable suspension path | high | mitigate | The handler's `Parley` reuses the existing HITL-01 suspension path rather than a parallel one, pinned by an acceptance criterion counting the `AwaitingInput` construction sites |
| T-25-55 | Elevation of Privilege | a handler consuming retry budget to extend a node's lifetime | low | mitigate | A `Parley` is not an attempt failure and consumes no retry budget (plan 25-07), pinned by `a_handler_raised_parley_does_not_consume_the_retry_budget` |
| T-25-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package: RESEARCH.md's Package Legitimacy Audit records zero proposed packages, verified by direct `Cargo.toml` read |
