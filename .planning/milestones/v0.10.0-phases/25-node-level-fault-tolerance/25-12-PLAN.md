## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| concurrent Muster tasks -> shared engine state | Many retrying tasks run in parallel against one superstep snapshot and one aggregation |
| abort signal -> a node sleeping in backoff | A shutdown must reach a task that is not currently executing anything |
| persisted Waypoint -> resume after a kill | A partially attempted node's state must not be mistaken for progress |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-56 | Tampering | cross-task retry-state leakage under concurrency | high | mitigate | The multi-thread stress asserts exact per-task counts with no tolerance, so any shared counter or shared backoff state shows up as a count mismatch rather than as flakiness (X-05, D-31) |
| T-25-57 | Denial of Service | shutdown grace consumed by a sleeping backoff | high | mitigate | The kill-during-backoff test asserts the abort returns well inside the remaining backoff, proving the `select!` in `wait_backoff` (D-15, RESEARCH Pitfall 7); the node is recorded `Skipped` and re-listed for exactly-once resume |
| T-25-58 | Tampering | a resume continuing a partially attempted node | high | mitigate | No Waypoint is written between attempts, so a resume can only restart the node at attempt 1 (D-17, FT-FR-07), asserted directly by `resuming_after_a_kill_during_backoff_restarts_at_attempt_one` |

| T-25-60 | Denial of Service | a stress or timing test hanging CI | medium | mitigate | Every concurrent test carries a timeout guard following the `listener.rs` house pattern, and the timing tests use a paused clock rather than wall-clock sleeps |
| T-25-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package: RESEARCH.md's Package Legitimacy Audit records zero proposed packages, verified by direct `Cargo.toml` read |
