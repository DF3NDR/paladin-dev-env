<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider HTTP response → `LlmError` → logs and model context | Third-party response bodies cross into errors that are rendered and sometimes shown to a model |
| configured API key → outbound request headers → redirects | A credential crosses a network boundary and could be forwarded onward |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-11 | Information Disclosure | a credential surviving into a rendered provider error | high | mitigate | The suite carries a dedicated case asserting no rendered error — `Display`, `Debug` or bounded excerpt — contains the configured key, with the key placed near the truncation boundary so a bound-then-redact implementation fails the case (D-31, D-34, security.instructions.md) |
| T-26-46 | Information Disclosure | a credential header forwarded on a cross-host redirect | high | mitigate | The suite carries a case asserting a 302 to a different host is not followed while carrying the credential header — the explicit rule in `security.instructions.md`'s manual-review list, now measured per adapter rather than reviewed by eye |
| T-26-47 | Repudiation | a transience misclassification hiding a retryable failure | medium | mitigate | Transience is asserted **by value** through `LlmError::transience()` for 408/429/5xx and other 4xx, never by parsing a message; this measures Phase 25 D-03's `map_http_status` on every adapter rather than trusting that it is reached (FT-FR-01) |
| T-26-48 | Repudiation | a conformance claim that measured nothing | medium | mitigate | Every adapter is feature-gated, and a filter selecting zero tests exits 0 — so the acceptance criteria assert the *reported test count* against adapters x cases, and Test 1 makes a silently dropped case a build failure rather than a quiet pass |
| T-26-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package; `mockito` is already a dev-dependency |
</threat_model>
