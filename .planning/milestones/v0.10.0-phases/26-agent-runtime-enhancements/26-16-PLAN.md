composite that unions several arsenals into one, the two `vault_get` / `vault_put` Armaments confined

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model-supplied tool arguments → `Namespace::new` → `ConfinedVault` → the store | The model is an untrusted caller addressing a shared store |
| model-supplied value → `vault_put` → durable storage | Model-authored content becomes durable and is later recalled into a prompt |
| several arsenals → one composite → one tool namespace | Tool-name collisions decide which implementation a model reaches |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
