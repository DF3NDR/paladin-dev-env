<objective>
Turn 27-01's single-branch worker into the durable worker pool PLAT-FR-02/03/06 describe: lease
heartbeats, resume-not-restart dispatch on redelivery, one shared `attempt` counter, `AwaitingInput`
releasing the worker by ACK, and drain-on-shutdown through the existing `ShutdownCoordinator`.

Purpose: the queue makes execution durable only if a killed worker's run is picked up and *continued*
from its Waypoint; this plan proves that with an InMemory twin of PRD acceptance 2 (the Redis twin
runs in CI via 27-03's job).

Output: `RunWorkerPool` with `RunWorkerOptions { concurrency, lease, min_probe_interval }`,
`LeaseHeartbeat`, `WorkerDispatch`, the outcome→status mapping table, and a `worker_tests.rs`
module carrying `worker_pool_lease_expiry_exactly_once`, `awaiting_input_acks_queue`,
`heartbeat_extends_at_lease_over_four` and `shutdown_drains_in_flight_run`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Queue message → worker | A dequeued pointer is untrusted until the `Run` is re-read from the repository (D-07). |
| Worker → engine | The worker drives the engine on behalf of an API caller; a wrong dispatch could re-execute side-effecting nodes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-04-01 | Tampering | queue message contents | high | mitigate | The worker never trusts the message payload: it re-reads the `Run` through `RunRepositoryPort` and branches on the persisted status; a stale/terminal message is ACKed and dropped. |
| T-27-04-02 | Elevation of privilege | duplicate execution via redelivery | high | mitigate | Dispatch resumes from the latest Waypoint (D-09); `worker_pool_lease_expiry_exactly_once` asserts every node ran exactly once. |
| T-27-04-03 | Denial of service | lost work on shutdown or crash | medium | mitigate | Drain via `ShutdownCoordinator` + NACK(0) on shutdown-halt (D-13); lease expiry redelivers on crash — primary boundary, mitigated. |
| T-27-04-04 | Information disclosure | `EngineError` text stored in `Run.error` | low | accept | Engine errors name node ids and limits, not credentials (Phase 25's redaction of provider bodies happens below the engine, `paladin-llm/src/redaction.rs`); the string is bounded by the engine's own error `Display`. |
</threat_model>
