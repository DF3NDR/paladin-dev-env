<objective>
Make cancellation cross-instance and durable: a narrow engine seam (`CancellationProbe`), a
debounced DB-backed adapter, and a persisted-flag-first `cancel` operation on the submission port,
proven by a two-instance test.

Purpose: PLAT-FR-04 — `POST /runs/{id}/cancel` must reach a worker on another instance at superstep
boundaries. The HTTP route itself lands with the rest of the run controller in 27-15; this plan ships
the mechanism and the service operation the route calls.

Output: `cancellation_probe.rs` (ports), `WarEngine::with_cancellation_probe` + the superstep consult,
`DbCancellationProbe` + `LocalRunTokens` (facade), `RunSubmissionPort::cancel`, and
`cancel_tests.rs` with `cross_instance_cancel_probe`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API caller → cancel flag | Any authenticated principal may request cancellation of a run (authorisation is D-46's invocation tier, enforced in 27-15). |
| Repository → engine boundary | A probe read failure must not decide a run's fate. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-07-01 | Denial of service | probe hammering the database on fast graphs | medium | mitigate | `DbCancellationProbe` caches per thread for `min_probe_interval` (D-15); counting-mock test. |
| T-27-07-02 | Tampering | lost cancel between flag write and local signal | medium | mitigate | Flag first, signal second (D-16); the flag alone is sufficient because the probe reads it. |
| T-27-07-03 | Denial of service | probe failure failing a run | high | mitigate | Signature is infallible; adapter returns `false` on error with a `warn` log; unit test. |
| T-27-07-04 | Elevation of privilege | cancelling another caller's run | medium | transfer | Authorisation belongs to the HTTP layer (27-15, D-46 invocation tier over the same auth middleware as `/v1/agents/*`); the service is process-internal. |
</threat_model>
