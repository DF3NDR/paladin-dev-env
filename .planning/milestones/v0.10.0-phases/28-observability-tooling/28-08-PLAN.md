internals — which is exactly PRD 07's stated intent.

    - `node_not_executed` passes when a node has zero `NodeStarted` records and fails with the visit

    - `edge_fired { from, to }` passes when an `EdgeEvaluated` record with those endpoints and

      explicitly rather than reporting the edge as absent.
    - `route_taken` treats its node list as a SUBSEQUENCE of the `NodeStarted` order — extra nodes in
      between are allowed, order violations are not; the failure renders the observed route.
    - `run_status` compares against `RunFinished.status`; `total_tokens_max` and `supersteps_max`
      compare against `RunFinished.total_tokens` / `total_supersteps`; a stream with no `RunFinished`
      record fails with a message saying the run never finished, never a panic or a default.
    - `parley_raised { kind, node }` matches a `ParleyRaised` record on both fields.
    - `final_state_snapshot` compares the serialized final Battlefield against the case's blessed
      snapshot file, reporting the first differing path when they differ; an absent snapshot file is a
      failure naming the bless flag, never an implicit pass.
  </behavior>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Scenario-supplied assertion parameters → evaluator | Field names, regexes and JSON paths from an untrusted document drive evaluation logic. |
| Failure rendering → developer console / CI log | Rendered failures include observed state, which could carry fixture content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-08-01 | Denial of service | A pathological regex in `final_state_field_matches` | medium | mitigate | Regexes are compiled through the `regex` crate, which has no backtracking and linear-time guarantees by construction; a compile failure is a typed assertion failure, not a panic. |
| T-28-08-02 | Elevation of privilege | `custom(fn)` reachable from a scenario file | high | mitigate | The custom hook is a Rust-API-only type with no serde derive and no variant in the file-format enum; asserted by a zero-occurrence check in `scenario.rs`. |
| T-28-08-03 | Information disclosure | Rendered failures echoing state values into CI logs | low | accept | Failures must show observed values to be actionable, and scenarios are scripted fixtures rather than production data; documented in `render_failure`'s rustdoc. |
| T-28-08-04 | Repudiation | A silently-passing assertion whose evidence never existed | high | mitigate | Every evaluator that depends on a `RunFinished` record fails explicitly when the stream has none; `evaluate` dispatches with no wildcard arm; an absent snapshot file is a failure, never an implicit pass. |
</threat_model>
