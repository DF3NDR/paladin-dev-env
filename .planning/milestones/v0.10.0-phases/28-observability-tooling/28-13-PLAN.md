`pub async fn run_x(..) -> Result<(), CliError>` taking already-parsed arguments, `OutputFormatter`

ADR-0023: the CLI is `cli`-gated and in-process; it has no HTTP client and must not gain one. An
`--assistant` or `--run` lookup goes through the assistant and run repository ports over the store
the loaded configuration names (SQLite locally, Postgres by URL), exactly as the server would.

`WaypointPort::history(thread, limit, before)` (`crates/paladin-ports/src/output/waypoint_port.rs:212`)
is the always-available overlay source; `RunTracePort::read` (28-04) is the exact one when persistence
is on.

harness invocation shape.

D-23's "both write to stdout by default (pipe-friendly, no colour)" is a locked behaviour, not a
default to be reconsidered.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments → filesystem and storage | Caller-supplied paths, thread ids and run ids drive reads and an optional write. |
| Stored execution history → developer terminal / file | Run history becomes a shareable artifact outside the server's auth boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-13-01 | Elevation of privilege | The CLI gaining a network path to the API | medium | mitigate | Both commands reach storage through ports only, asserted by a zero-occurrence check on the HTTP client crate in each file; ADR-0023's isolation is preserved. |
| T-28-13-02 | Information disclosure | Exported overlays carrying state content | medium | mitigate | The overlay carries ids, outcomes, counts and costs only; field values never enter `ExecutionOverlay`. |
| T-28-13-03 | Tampering | `--out` writing to an unexpected location | low | accept | The path is supplied by the operator running the command on their own machine, with the same authority the shell already grants; path traversal generally is canon and covered by the manual review. |
| T-28-13-04 | Repudiation | A derived overlay presented as exact | medium | mitigate | The command prints the resolved source and whether the shape is observed-only, and the diagram itself carries the locked observed-only title. |
</threat_model>
