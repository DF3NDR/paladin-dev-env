<objective>
Carry the full usage object across the HTTP edge: a `TokenUsageResponse` DTO in `paladin-web`,
`ExecuteResponse.usage` and the inspector's `CompletedRow.usage` in place of their bare counts, the
dev-UI row following, and a regenerated OpenAPI baseline (D-24; ACCT-02's "no carrier collapses the
split", ACCT-05's OpenAPI gate).

Purpose: leaving a bare count on the published wire would re-create the exact collapse this phase
exists to remove, one layer above the carrier — and would force a second breaking change to the
HTTP contract after 1.0. The edge changes now, while ADR-0051 sanctions the break.

Output: an HTTP response contract that carries the split, a regenerated `openapi.json`, and a test
proving the SSE trace payloads carry it too.
</objective>
