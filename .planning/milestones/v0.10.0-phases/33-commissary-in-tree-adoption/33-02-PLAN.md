<objective>
Make the shed record visible where a human and an LLM actually read it. Plan 33-01 put
`Vec<ShedItem>` on the result; this plan emits the RAG-level omission marker from BOTH renderers
through one shared helper so the two can never drift (D-15), and adds the counts-only observability
line (D-16). Tests assert both directions: marker and shed present when the budget is exceeded,
both absent when everything fits (COMM-02).

Purpose: "nothing is dropped silently" is only true if the drop is visible in the rendered prompt,
not merely in a struct field the caller may ignore.
Output: one marker helper, two renderers that call it, and the both-directions tests.
</objective>
