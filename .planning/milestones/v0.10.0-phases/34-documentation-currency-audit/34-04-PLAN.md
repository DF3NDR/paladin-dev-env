<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository working tree → git commit | A commit carrying a file outside `.planning/` falsifies SC5 |
| page content → recorded verdict | A verdict inferred from a page's recency rather than its content is indistinguishable on disk from a measured one |
| deployment pages → captured evidence | These pages carry connection strings, bucket names and credential placeholders; quoting one into the evidence file could publish a real value if a page has drifted into holding one |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-34-01 | Tampering | phase commits (`git add`) | high | mitigate | Both task verifies require `git status --porcelain -- . ':!.planning'` empty and `34-check.sh --seed` green, which repeats the merge-base diff (D-22) |
| T-34-02 | Information Disclosure | quoted snippets from `deployment/` and `operations/` pages in findings cells and `34-EVIDENCE.md` | high | mitigate | Findings cells quote identifiers and `file:line`, never a full credential-bearing line; before commit the audit and evidence diffs are grepped for key-shaped tokens (`sk-`, `_API_KEY=`, `AWS_SECRET`) and any hit is redacted before the surrounding text is truncated, per the house rule in `crates/paladin-llm/src/redaction.rs`. If a page is found to contain a real credential, that is itself a finding routed to the deferred register with the value redacted in the row |
| T-34-03 | Repudiation | §2 verdict rows | medium | mitigate | `34-check.sh` assertion (c) fails a settled row whose findings cell is empty or still the placeholder; acceptance criteria require named signal-class commands per row (D-00b, D-07) |
| T-34-04 | Tampering (supply chain) | package installs | low | accept | Nothing is installed; this plan runs `grep`, `awk` and `git` only |
| T-34-05 | Denial of Service | devcontainer resources | low | accept | No build runs in this plan |
</threat_model>
