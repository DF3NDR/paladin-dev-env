## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository working tree → git commit | A commit carrying a file outside `.planning/` falsifies SC5 |
| setup/appendix pages → captured evidence | The MinIO, Redis and user-system setup pages carry credentials, tokens and connection strings in example form; quoting one wholesale could publish a real value if a page has drifted |
| page content → recorded verdict | A verdict inferred from a page's age rather than its content is indistinguishable on disk from a measured one — and this is the partition where age is most tempting as a proxy |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-34-01 | Tampering | phase commits (`git add`) | high | mitigate | Both task verifies require `git status --porcelain -- . ':!.planning'` empty and `34-check.sh --seed` green (D-22) |
