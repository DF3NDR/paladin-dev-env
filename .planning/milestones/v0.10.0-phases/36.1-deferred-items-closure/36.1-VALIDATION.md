## Sampling Rate

- **After every task commit:** the task's own `<automated>` command (a doctest filter, a `grep` count, or the gate script), each of the doc-writing tasks also re-measuring the crate with `cargo doc … 0 warning:`
- **After every plan wave:** `cargo doc --workspace --no-deps` with zero `warning:` lines (the workspace figure was re-measured after plans 36.1-08, -09, -10 and -12)
- **Before `/gsd-verify-work`:** `make api-surface`, `bash scripts/check-public-api-examples.sh`, the docs gate sequence and `gsd-tools windows status` (the 2026-09-18 seal ran them; a re-verification followed the review fixes)
- **Max feedback latency:** 36 seconds for a single doctest filter or `make check-api-examples` on a warm checkout (the all-features test build and `cargo doc --workspace` are compile-bound and excused)
