<objective>
Teach the two native adapters whose effort form depends on the model -- Anthropic (`output_config.effort` vs the
legacy `thinking.budget_tokens`) and Gemini (`thinkingLevel` vs `thinkingBudget`) -- to map each value exactly as the
model's profile allows, or refuse before HTTP.

Purpose: REASON-02 (model-aware `map_reasoning` in each native adapter), REASON-03 (exact wire bodies), REASON-05
(reasoning text and tokens still reach the typed surface), REASON-06 (budget bounds and `max_tokens`). D-00h decides the
Anthropic strategy. Anthropic leads because web3sec's production model is `claude-opus-4-8`.

Output: private request fields, `map_reasoning` and caps constants in two adapter files, with wire-body tests written
red first. This plan edits no shared file (no CHANGELOG, baseline or register: the surface is private), so it runs
beside plan 51-04; plan 51-06 records the behaviour change in the CHANGELOG.
</objective>
