<objective>
Make a corrupt or half-attributed run row answer by role: the missing-run `404` to a non-admin and the fixed redacted `500 "run store error"` to an Admin, with the detail only in the server log (TENANT-06, D-09, D-10). The rule is written once as a `pub(crate)` helper that plan 53-03 reuses for the thread routes and for waypoint errors (orchestrator note 4).

Purpose: a non-admin can no longer learn that an unreadable run exists under an id; the redaction rule exists in exactly one place.
Output: `redact_store_error_for_scope` and `run_repo_error_for_scope` in `run_controller.rs`, `load_visible_run` routed through them, a route-matrix test over the four `/v1/runs/{run_id}*` operations, an AC-11 test, `MIGRATION.md` and CHANGELOG entries.
</objective>
