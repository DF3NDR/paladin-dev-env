Make an unexpanded `${…}` placeholder impossible as an HTTP API key (FIRST-01, D-01..D-04). `AuthConfig::validate` refuses it at config load and names the entry, never the value. The shipped `config.example.yml` stops carrying a loadable placeholder and stops implying that the server expands one, and the behavioral change is recorded in `MIGRATION.md` §11 and `CHANGELOG.md` `[Unreleased]`.
