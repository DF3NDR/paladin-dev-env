<objective>
Deliver the `paladin-server` config on Kubernetes as a Secret (FIRST-01, D-05). The config holds literal API keys and the server reads exactly one file with no `${VAR}` expansion, so a ConfigMap of placeholders can never be both safe and working. Bring every `k8s/` version label and first-party image tag to the workspace version, and make `make docker-build-server` produce that tag (FIRST-04, D-09, D-10). Rewrite the `k8s/README.md` quick start into a clean copy-paste sequence, and record the move in CHANGELOG and MIGRATION.

Purpose: the shipped k8s manifests stop loading `${PALADIN_API_KEY_*}` as credentials, a copied manifest can find the image the documented build produces, and the plan 54-07 gate has a green `k8s/` tree to hold.
Output: the Secret template, two Deployments, the root Deployment's labels, the README, a Makefile recipe, and CHANGELOG/MIGRATION entries; `configmap.yaml` is removed.
</objective>
