<planner_decisions>
- **PD-13-1 (one plan, two findings).** 45 WR-04 and 45 WR-06 change the same Err arm; one plan, Task 1 then Task 2, avoids two plans editing `worker.rs` (the 57-10 hand-off rule).
- **PD-13-2 (halts included).** The halt exits share `emit_agent_run_finished` and have the same emit-before-write order. Leaving them would keep the defect the review names ("the terminal wire event before the durable status write") on two of `run_agent`'s exits and make the new rustdoc false. They take the same `on_committed` callback and one regression test. Their error propagation (`?`, lease expiry redelivers) is unchanged.
- **PD-13-3 (success-path write failure nacks).** On the success arm a failed `update_status` or `record_outcome` now logs one `warn!` (run id and repository error only, P-13-3) and nacks with a 1 s delay, returning `Ok(true)`, exactly as `persist_failure`'s repository-error branch already does; v0.11.0 propagated the error and waited for lease expiry. A failed `ack` keeps propagating the queue error (a nack on the same lease token after a failed ack is not meaningful); no terminal event is emitted either way.
- **PD-13-4 (45 WR-06 design point, rated reversible).** The open design point was how partial usage and cost cross the error. Three shapes were weighed:
  - a field on `PaladinError`: rejected; it would change most variants of a public enum (more than additive under D-00b), and `spend_scope.rs`'s own rustdoc already rejected it for the same reason;
  - a returned tally (a new `PaladinPort` method or return type): rejected; a public port change;
  - the existing public `ATTEMPT_SPEND` task-local carrier (plan 50-29), which `PaladinExecutionService` already feeds at every fold: chosen. The worker installs a scope; no public item, no wire or storage format changes, and an out-of-tree `PaladinPort` that records nothing still reports zero, as today.
  Undoing it is a local revert in one function, so the rating is `reversible` and no `checkpoint:decision` is needed.
- **PD-13-5 (WINDOWS phase column).** `--phase 45`, the origin phase, as rows 88-93.
