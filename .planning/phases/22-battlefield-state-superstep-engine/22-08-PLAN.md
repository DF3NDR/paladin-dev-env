<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Battlefield -> Paladin prompt | Shared state is rendered into a string that is sent to an external LLM provider |
| stored Waypoint -> restored engine state | Previously persisted vanguard, visit counts and state are trusted back into a live run |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-26 | Spoofing | `resume` continuing against a graph the Waypoint was not written for | high | mitigate | The stored `GraphFingerprint` is compared before any node executes, failing with `GraphMismatch { expected, got }`; the only bypass is an explicit `allow_graph_change` flag which then fails precisely with `VanguardNodeMissing { node }` rather than silently dropping unknown nodes |
| T-22-27 | Elevation of Privilege | a resume that resets per-node visit counts, turning a bounded loop unbounded | high | mitigate | Visit counts are persisted on the Waypoint and restored by `resume`, with a dedicated test asserting a node interrupted at 4 of 5 visits trips its limit on the next post-resume visit |
| T-22-28 | Information Disclosure | `InputMapping` rendering a secret-bearing field into an outbound LLM prompt | medium | accept | Which fields a template reads is entirely the graph author's choice and is visible in the template; the engine adds no implicit field. Accepted with the control that a placeholder naming an undeclared field is a typed error, so a template cannot silently pull in or silently drop content |
| T-22-29 | Tampering | a template placeholder silently substituting empty text and truncating a prompt | medium | mitigate | An unresolvable placeholder is a typed error rather than an empty substitution, unit-tested for the undeclared-field and no-default cases |
</threat_model>
