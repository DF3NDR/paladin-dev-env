<objective>
Make a Battalion nest: `NodeSpec::Battalion` embeds a child `WarGraph` as a node, with `StateMap`
declaring exactly what crosses in and out, the child inheriting the parent engine wholesale, and
recursive embedding rejected before anything runs.

Purpose: subgraph composition is what gives "a Formation inside a Campaign" for free and is the
last structural capability the engine is missing. The composition boundary has to be exact — the
`StateMap` is the whole contract, and anything the child keeps must stay the child's.

Output: the `Battalion` variant and `StateMap`, a child run that maps state in and out under the
parent's dispatch rules, full engine inheritance, and typed validation for mapped fields and
recursion.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parent Battlefield <-> child Battlefield | The `StateMap` is the complete, declared channel between two state namespaces; anything crossing it that was not declared is a boundary violation. |
| parent engine resources -> child run | The child inherits the parent's ports, registries, trace sink and cancellation token; a resource silently not forwarded is a capability the child then lacks (or, for the registries, a validation the child then skips). |
| graph author -> nesting depth | An author-supplied `Arc<WarGraph>` chain determines recursion depth at validation and stack depth at execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-31 | Information Disclosure | unmapped child fields reaching the parent or its Waypoint | high | mitigate | Only `StateMap.outputs` are read out of the child's final state; no code path copies the child Battlefield wholesale. Asserted by `unmapped_child_fields_stay_private`, which checks the parent Battlefield AND the parent thread's Waypoint payload for both the field name and its value. |
| T-23-32 | Denial of Service | recursive or unbounded subgraph nesting | high | mitigate | `EngineError::RecursiveEmbedding` rejects cycles at validation via a path-set walk over child fingerprints, before any node executes — bounding nesting depth by construction; `deep_but_acyclic_nesting_validates` proves the check discriminates cycles from depth rather than capping legitimate composition. |
| T-23-33 | Elevation of Privilege (a child escaping the parent's fail-closed contract) | child validation registries | high | mitigate | The child is validated with the SAME dispatch resolver and edge-evaluator registry as the parent, so an unregistered `Custom` edge condition or dispatch rule inside a child fails validation exactly as it does in the parent — asserted by `child_graph_is_validated_with_the_parents_registries`. Without this a subgraph would be a hole in CF-01's fix. |
| T-23-34 | Tampering (of parent state via a child's output) | mapped outputs merged into the parent | medium | mitigate | Mapped outputs are applied as an ordinary `StateDelta` under the PARENT's dispatch rules and the parent's schema, so a child cannot write a field the parent never declared, nor bypass the parent's merge semantics. |
| T-23-35 | Denial of Service | a child ignoring cancellation | medium | mitigate | The parent's cancellation token is forwarded to the child, which observes it at its own superstep boundary and persists `Halted`; asserted by `cancellation_is_observed_at_the_child_superstep_boundary`. |
| T-23-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no packages and modifies no manifest; `23-RESEARCH.md` §Package Legitimacy Audit records zero external package additions for the phase. |
