<objective>
Land the Parley value types in `paladin-core` and prove the suspend-persist-resume spine
end-to-end through the engine and a Waypoint backend. This is the phase's tracer: one thin
path (one node raises one parley, the run suspends, a different `resume_with` call delivers
one response, the run completes) wired through every layer the parley half of Phase 24
modifies, with real error handling on that single path.

Purpose: prove the architecture of HITL-01/HITL-02 before any horizontal expansion (Gate
node, validation matrix, expiry, HTTP) is built on top of it. Everything after this plan
expands out from the proven slice.

Output: `parley.rs` value types, the reshaped `AwaitingInput` Waypoint payload, the reshaped
`RunOutcome::AwaitingInput`, `WarEngine::resume_with`, `NodeContext.parley_response`, and the
typed guards that stop a plain `resume` or a nested-Battalion parley from silently doing the
wrong thing.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| graph author -> `ParleyRequest.payload`/`prompt` | Author-controlled content is persisted verbatim into the Waypoint store and later read back by resume and (from plan 24-11) the HTTP `state` endpoint |
| caller -> `resume_with(thread, responses)` | A caller-supplied `ParleyId` set is matched against the loaded thread's own outstanding parleys |
| process A -> WaypointPort -> process B | A suspended thread's entire state crosses processes through the persisted Waypoint only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-01 | Spoofing | `WarEngine::resume_with` parley-id matching | high | mitigate | `UnknownParleyId` membership is checked against the loaded `AwaitingInput` Waypoint's own `parleys` list for the requested `ThreadId` only — never a global parley-id lookup across threads (D-10) |
| T-24-02 | Information Disclosure | `ParleyRequest.payload`/`prompt` persisted verbatim | medium | mitigate | No API key, secret or provider credential is written into a `ParleyRequest` by engine code; the raise path copies only author-supplied template output. The graph-author warning ships with the mdBook page in plan 24-12 |
| T-24-03 | Tampering | Resume against a redeployed graph | high | mitigate | `resume_with` performs the same `GraphMismatch` fingerprint check `resume` already does (ENG-FR-14) before any state change; a mismatch returns a typed error and writes nothing |
| T-24-04 | Denial of Service | A suspended thread holding engine resources | medium | mitigate | Suspension releases every task, timer and connection for the run before returning `RunOutcome::AwaitingInput`; the only retained state is the persisted Waypoint |
| T-24-SC | Tampering | package-manager installs | low | accept | This phase installs no new package in any crate — RESEARCH.md's Package Legitimacy Audit records zero proposed packages, verified by direct `Cargo.toml` read |
</threat_model>
