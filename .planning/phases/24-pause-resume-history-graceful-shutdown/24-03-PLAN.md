<objective>
Let an LLM-backed Paladin node raise a parley through the structured directive envelope, and let
any re-run node read its answer through a dedicated `NodeContext` namespace that the Battlefield can
never shadow.

Purpose: HITL-FR-04's "delivers values to the paused node's continuation" for Function and Paladin
nodes — the half of D-07 the Gate node does not cover.

Output: the envelope `next.parley` key, `InputMapping::render`'s parley context parameter and
namespace resolver, and the graph-validation rule that reserves the prefix.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM output -> `DirectiveParser` envelope | Model-generated JSON is parsed into a `ParleyRequest` that is then persisted and shown to a human |
| Battlefield schema -> namespaced placeholder | A schema field could otherwise shadow a `NodeContext`-only namespace |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-09 | Spoofing | A schema field shadowing a parley-namespaced placeholder to feed a node an attacker-influenced "response" | high | mitigate | The resolver never falls through to a Battlefield read for a namespaced placeholder, and `WarGraph::validate` independently rejects declaring a schema field with the reserved prefix — two independent controls, mirroring the shipped muster rule |
| T-24-10 | Elevation of Privilege | An LLM-authored `ResumeWithDefault` value bypassing an approval decision | high | mitigate | The directive path calls the same shared per-kind validator as graph validation and `resume_with`; a value that does not satisfy its kind is rejected at raise time |
| T-24-11 | Tampering | A malformed envelope degrading a parley into ordinary edge resolution | high | mitigate | A malformed parley entry routes through the existing `OnParseError` policy; `NextStep::Parley` is never coerced to `NextStep::Edges`, pinned by a test |
| T-24-12 | Information Disclosure | Model-authored `prompt`/`payload` persisted and later served over HTTP | medium | mitigate | Content is author/model supplied and never enriched with engine-held credentials; the graph-author warning ships with the mdBook page in plan 24-12 |
| T-24-SC | Tampering | package-manager installs | low | accept | No new package is installed by this plan |
</threat_model>
