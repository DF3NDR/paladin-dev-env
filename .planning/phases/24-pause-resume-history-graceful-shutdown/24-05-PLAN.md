## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process A -> SQLite Waypoint file -> process B | The only channel a suspended thread crosses; a defect here is a durability defect, not a memory defect |
| concurrent resumers -> one shared store | Ten simultaneous `resume_with` calls against one backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-18 | Spoofing | Cross-thread response delivery under concurrency | high | mitigate | Task 3 asserts a parley id from one thread is `UnknownParleyId` against another, and that each thread's final Battlefield carries only its own response value |
| T-24-19 | Denial of Service | A deadlocked concurrent resume hanging the suite | medium | mitigate | Task 3 wraps the scenario in an explicit `tokio::time::timeout` so a hang fails fast |
| T-24-20 | Tampering | A suspended thread silently resuming against stale in-process state instead of the persisted Waypoint | high | mitigate | Every cross-process assertion reads through a freshly constructed engine and store handle; assertions read `WaypointPort`, not engine return values |
| T-24-SC | Tampering | package-manager installs | low | accept | No new package is installed by this plan; all fixtures are existing test-support types |
