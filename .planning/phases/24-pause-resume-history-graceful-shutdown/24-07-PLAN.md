<objective>
Make the Chronicle forkable: re-enter the engine from any past Waypoint, optionally with an edit,
producing a new branch while the original chain stays byte-identical — and expose the read side as a
thin port-only application service both the facade and the HTTP adapter can share.

Purpose: HITL-03 and HITL-FR-07 through FR-12, including the immutability hard invariant and the
subgraph-fork semantics.

Output: `WarEngine::replay`, `WarEngine::fork`, branch-scoped subgraph child threads, and
`ChronicleService`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> `fork(thread, from, edit)` | A caller-supplied `StateDelta` is merged into a workflow's state before the branch runs |
| branch -> mainline chain | A branch must be incapable of altering the chain it started from |
| branch child thread -> mainline child thread | Subgraph histories must not cross |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-25 | Tampering | A fork edit mutating the original chain | high | mitigate | `replay`/`fork` only append new Waypoints; Test 2 asserts byte-for-byte mainline equality before and after, and Test 3 asserts a second replay does not disturb the first branch |
| T-24-26 | Tampering | A fork edit naming an undeclared schema field | high | mitigate | The edit is merged through the schema's dispatch rules and rejected with a typed error before the first forked superstep, persisting nothing |
| T-24-27 | Information Disclosure | A branch reading or overwriting the mainline subgraph child's history | high | mitigate | Branch children run under `ThreadId::child_on_branch`; isolation comes from the derived id alone, with no marker-based lookup path |
| T-24-28 | Tampering | `replay`/`fork` advancing a thread against a redeployed graph | high | mitigate | Both check the graph fingerprint against the starting Waypoint before anything else and return `GraphMismatch` with nothing persisted |
| T-24-29 | Information Disclosure | `ChronicleService` exposing full Waypoint content beyond what a caller may see | medium | mitigate | The service performs no authorisation of its own by design; authorisation is enforced at the HTTP adapter's `route_layer` (plan 24-11), and this split is documented on the service |
| T-24-SC | Tampering | package-manager installs | low | accept | No new package is installed by this plan |
</threat_model>
