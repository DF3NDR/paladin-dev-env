a durable backend when one is configured.

## Flagged assumptions (unresolved edge probes)

The spec-less edge-coverage probe produced one `unclassified` item for HITL-05 that could not be
auto-resolved into an acceptance criterion. It is recorded here rather than silently dropped:

- **HITL-05 / unclassified — "review manually".** The probe generator could not classify this
  requirement into an edge family. The planner's reading is that the residual ambiguity is *history
  pagination behaviour when the Chronicle mutates between pages* — specifically what a client sees
  when new Waypoints are appended while it is paging with an opaque cursor. This plan assumes the
  cursor is exclusive-by-waypoint-id over a newest-first ordering, so newly appended Waypoints
  appear only on a fresh first page and never duplicate into a later page. That is an assumption,
  not a decision carried from CONTEXT.md or PRD 03. PLAT-06 (Phase 27) owns the general
  opaque-cursor policy and may formalise or change it; surface this at plan review.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated internet -> `/v1/threads/*` | Every thread route must be behind the same authentication as the agent routes |
| Waypoint content -> HTTP response body | The state endpoint returns Waypoint-derived content that may contain raw prompts and model output |
| client -> resume request body | Untrusted JSON becomes a `ParleyResponse` delivered into a running workflow |
| client -> `limit`/`cursor` query parameters | Untrusted pagination parameters reach a storage query |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-44 | Spoofing | Unauthenticated access to thread state or resume | high | mitigate | `thread_openapi_router` applies the same `require_authentication` `route_layer` as `/v1/agents/*`, pinned by a test asserting an unauthenticated request is rejected |
| T-24-45 | Information Disclosure | `GET /v1/threads/{id}/state` returning raw prompts, model output or an author-embedded secret | high | mitigate | The endpoint returns Waypoint-derived content only and adds no credential of its own; the graph-author warning against templating secrets into a Gate payload ships with the mdBook page in plan 24-12, and the interim any-authenticated-role posture is documented there rather than left implicit |
