<objective>
Land the Aegis skeleton end-to-end: the core value types (`Transience`, the structured `NodeError`
family, the whole `Aegis` policy family), the `WarGraph` sidecar that attaches an `Aegis` to a node,
and the retry loop that wraps the per-node dispatch closure in `superstep.rs` — proven by one run in
which a genuinely failing node retries in place and the run completes.

This is the phase's **tracer**. It is production code, not a prototype: the types land in their final
shape (nothing after this plan reshapes `Aegis` or `NodeError`), the retry loop is
cancellation-aware from the first commit, and the single wired path carries a real end-to-end
`<verify>`. Everything after this plan — timeouts, handlers, cache, fallback — expands out from the
proven slice instead of discovering an architectural dead end after ten committed layers.

Purpose: prove the one architectural risk of FT-02 (that the Aegis wraps **outside** the interceptor
chain and that attempt isolation falls out of the existing snapshot discipline) before any
horizontal expansion is built on it.

Output: `transience.rs`, `node_error.rs`, `aegis.rs` in `paladin-core`; `engine/retry.rs`, the
`WarGraph` aegis sidecar, the `StateNodeError` rename, and a retry loop in `superstep.rs`.
</objective>
