<objective>
Land `AgentRuntimeConfig` — the single X-09 config home for all twelve built-in middlewares this
phase ships — with every sub-struct inert by default, so the eleven plans that follow each construct
their middleware from a sub-struct that already exists rather than inventing a config shape as they
go.

Purpose: X-09 requires a config struct with `Default`, `validate()` and `EnvOverridable` for every
tunable runtime behaviour, and MIGRATION §9.5 requires the disabled-by-default claim to be backed by
a test. Landing all twelve at once (D-10) means one module doc, one env-var naming scheme and one
inertness test rather than twelve scattered ones.

Output: `src/config/agent_runtime.rs` with `AgentRuntimeConfig` and its twelve sub-structs;
registration and re-export in `src/config/mod.rs` and `src/config/settings.rs`.
</objective>
