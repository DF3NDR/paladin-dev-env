    <option id="delete-mirror-now">
      <name>Proceed as D-17 locks it, deleting the root mirror in this change (recommended)</name>
      <pros>One reader of migrations, immediately: the class of bug where the container's copy and the crate's copy drift cannot exist; the `Dockerfile` gets smaller; the `SqliteWaypointStore` precedent already proves the embedded pattern in this workspace; plan 26-09's `SqliteVault` inherits one unambiguous numbering sequence.</pros>
