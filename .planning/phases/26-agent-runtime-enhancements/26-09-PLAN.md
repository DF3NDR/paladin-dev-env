## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| namespace + key → SQL `ns`/`key` columns | Caller-supplied addressing crosses into a query |
| vector backend results → returned records | A third-party index decides which entries are candidates |
| backend error text → `VaultError::Storage` | Storage-layer text crosses into an error a caller may log |
