<objective>
Make the Vault reachable from execution under a host-granted subtree: the `ConfinedVault` decorator
that enforces the grant before any backend call, the `RunScope` that carries a grant into a run, the
defaulted `PaladinPort::execute_scoped` that lets the engine pass one, and `WarEngine::with_vault` /
`NodeContext::vault()` so an engine node can read and write memory within its subtree.

Purpose: this is the access-control half of RT-04. `Namespace::is_prefix_of` (plan 26-04) is the
primitive; this plan is the enforcement point and the plumbing that decides *which* namespace a run
is confined to. Getting the "no grant means denied, never means root" rule right here is what makes
plan 26-16's attack test meaningful.

Output: `RunScope` in core; `ConfinedVault` in the facade; `PaladinPort::execute_scoped` as a
defaulted method; `execute_scoped` on the service; `WarEngine::with_vault` and `NodeContext.vault`.
</objective>
