## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator config → `build_chain` → the installed middleware set | Configuration decides which controls are actually in force on a run |
| preset defaults → a caller who reads no further | The one-liner's defaults are the security posture for anyone who does not customise |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-63 | Elevation of Privilege | a preset silently granting Vault access | high | mitigate | `reasoning_agent` does **not** enable vault tools; access remains a separate opt-in that additionally requires a run grant (D-21, D-22). `the_preset_does_not_enable_vault_tools` asserts neither tool is listed. |
| T-26-64 | Repudiation | `build_chain` silently dropping a control the operator configured | high | mitigate | A section enabled without its dependency is a **typed error**, not a skip, and every configuration failure is reported in one error rather than the first (`build_chain_requires_the_dependency_a_section_needs`, `build_chain_reports_every_configuration_failure_at_once`). Silently omitting a guardrail an operator asked for is the precise failure this prevents. |
| T-26-22 | Denial of Service | an unbounded tool loop in the preset | medium | mitigate | The preset installs a `ToolCallLimit` from `max_tool_calls` (default 20) and `max_loops` defaults to 5; `max_tool_calls_is_enforced` asserts the budget denies rather than fails |
| T-26-65 | Denial of Service | a failing provider hammered by the preset's default breaker | low | mitigate | The default `CircuitBreaker::new(3, 2, 30s)` is the README's published figure rather than an invented one, and `defaults_match_the_documented_options` pins it so a silent change is visible |
