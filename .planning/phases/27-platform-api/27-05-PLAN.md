<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stored assistant body → `compile()` | Arbitrary JSON authored by an admin over HTTP becomes an executable graph. |
| Document → registries | Names in the document select code (evaluators, handlers) registered in the process. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-05-01 | Tampering | `WarGraphDoc` → `WarGraph` | high | mitigate | `deny_unknown_fields`, typed `CompileError` for every unresolved name or structural fault, `validate()` invoked inside `compile()` — nothing partially compiled is ever returned. |
| T-27-05-02 | Elevation of privilege | naming arbitrary Rust behaviour from a document | high | mitigate | No `function` node kind exists; only names present in `EngineRegistries` resolve, and only kinds `paladin`/`gate`/`workflow` compile (D-33 correction). |
| T-27-05-03 | Denial of service | pathological documents (deep nesting, huge limits) | medium | mitigate | `LimitsDoc` maps onto `EngineLimits` whose `validate` rejects `max_supersteps == 0`; nested `workflow` depth is bounded by a `MAX_NESTING_DEPTH` (8) check in `compile()` returning `CompileError::NestingTooDeep`. |
| T-27-05-04 | Information disclosure | `system_prompt` in stored documents | low | accept | Documents are admin-authored and read only through authenticated routes (27-12); prompts are configuration, not credentials, and no credential field exists in the document. |
</threat_model>
