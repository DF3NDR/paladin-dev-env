assistant HTTP routes with synthetic code-registry entries.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin HTTP caller → definition bodies | Arbitrary JSON becomes an executable graph or agent config. |
| Any authenticated caller → run submission against a stored assistant | Role gating per assistant (`allowed_roles`). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-12-01 | Tampering | invalid or malicious definitions persisted | high | mitigate | Compile-is-validation before any repository write; `{}` → 400 + nothing persisted (test). |
| T-27-12-02 | Elevation of privilege | non-admin publishing assistants | high | mitigate | `require_admin` on create/version/delete (D-46); 403 test. |
| T-27-12-03 | Elevation of privilege | invoking an assistant outside its `allowed_roles` | medium | mitigate | `RunSubmissionService` enforces `allowed_roles` from the resolved definition → `Forbidden` (403 in 27-15). |
| T-27-12-04 | Information disclosure | credentials smuggled into definition bodies | medium | mitigate | `credential_field_forbidden` violation on `api_key`/`token`/`secret`/`authorization` keys (prohibition P1). |
| T-27-12-05 | Tampering | mutating code-registered entries | medium | mitigate | 409 `code_registered_immutable`; `AgentRegistry` untouched (X-03). |
</threat_model>
