`webhook_deliveries` table, an SSRF guard applied at write and send time, HMAC signing over the exact

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API caller → webhook URL / secret | Caller-chosen destination for server-originated HTTP with a credential-shaped header. |
| Server → arbitrary internet host | Outbound request may be redirected, time out, or reach internal networks. |
| Delivery rows → `GET /runs/{id}/webhook-deliveries` (27-15) | Persisted attempt records are readable by API callers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-13-01 | Spoofing / Elevation | SSRF via webhook URL (write and send, incl. redirects) | critical | mitigate | `SsrfGuard` table at write time and on resolved addresses at send time; `Policy::none()` client; metadata IP always rejected even with `allow_private`; DNS rebinding documented as a limitation. |
| T-27-13-02 | Tampering | signature mismatch via re-serialisation | high | mitigate | Payload stored as the exact string; signed and sent from that buffer; receiver-side verification test. |
