<objective>
Close code-review warning WR-04 and convert warnings WR-02 and WR-03 from silent gaps into
documented, tested, tracked limitations.

WR-04: `LeaseHeartbeat::spawn` computes `interval = lease / 4` and sleeps on it in a loop; with a
zero-duration lease that sleep resolves immediately, so the task calls `extend_lease` as fast as the
executor can schedule it. `RunWorkerConfig::validate()` keeps the production wiring off that path, but
`RunWorkerPool::new` and `LeaseHeartbeat::spawn` are both public API with no guard of their own.

WR-02: `run_once` dispatches an `Agent`-kind runnable before any event-bus bind/publish or
webhook-delivery enqueue, so a caller who sets `webhook` on a run against a code-registered agent
never receives a delivery — while the module docs describe the hook unconditionally.

WR-03: the three run read routes require only authentication, so any authenticated principal can
enumerate every run and read every webhook target URL in the deployment.

Purpose: PLAT-02 (worker mechanics), PLAT-03/PLAT-05 (the documented reach of streaming and delivery)
and PLAT-06 (the published API surface's honesty about what it does and does not promise).

Output: a guarded heartbeat with a test, two documented-and-pinned limitations, and two tracked
ledger rows so neither deferral can be forgotten.
</objective>
