Source-of-truth types (28-RESEARCH.md Q6, verified by direct read):
`crates/paladin-battalion/src/engine/graph.rs:42-160` — `NodeSpec` (`#[non_exhaustive]`) has exactly
four variants: `Paladin { paladin, input_template, output_field, directive_parser, output_schema }`,
`Function(Arc<dyn StateNode>)`, `Battalion { graph, state_map, restart_on_resume }` (the
Workflow/subgraph case) and `Gate { request, output_field }`. Worker-template and deferred are NOT
`NodeSpec` variants — they are private `HashSet<NodeId>` fields on `WarGraph`, queried via
`WarGraph::is_worker_template(&NodeId) -> bool` (`graph.rs:660-668`) and `WarGraph::is_deferred`
(`graph.rs:534-602`). Edges are `EdgeSpec { from: NodeId, to: NodeId, condition:
Option<EdgeCondition> }` (`graph.rs:451`) with `EdgeCondition = Always | Contains | Regex | Custom`.
`crates/paladin-battalion/src/engine/graph_doc.rs:335-342` — `NodeKindDoc` has exactly three
variants: `Paladin(PaladinNodeDoc)`, `Gate(GateNodeDoc)`, `Workflow(WorkflowNodeDoc)`. `NodeDoc`
(`graph_doc.rs:147-168`) carries `pub defer: bool` directly, so `from_doc` reads `deferred` with no
derivation and `worker_template` is always `false` on that path.

Badge glyphs and node-kind labels are frozen by `28-UI-SPEC.md`: `«paladin»`, `«function»`, `«gate»`,
`«workflow»`, `«worker»`, in guillemets, appended to the real node id in the label.

Bless idiom (`crates/paladin-battalion/tests/graph_doc_round_trip.rs:104-122`): a
`concat!(env!("CARGO_MANIFEST_DIR"), "/..")`-relative path helper, an
`if std::env::var_os("...").is_some() { write; return; }` branch, then an `assert_eq!` whose message
names the variable. `Makefile:370` shows the house form of a bless target.

Existing graph-doc fixtures: `crates/paladin-battalion/tests/fixtures/graph_docs/` currently holds
`approval_gate.json`, `nested_workflow.json`, `two_paladins_custom_edge.json`.

`crates/paladin-battalion/src/maneuver/visualizer.rs` (`FlowVisualizer::to_mermaid`, `flowchart LR`)
is a style reference for string building and escaping only — it is a different surface and stays
untouched.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Graph node ids and condition text → rendered diagram string | Author-supplied identifiers become diagram markup an operator's browser or Graphviz renders. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-07-01 | Tampering | Node id or condition text breaking out of a Mermaid/DOT label | medium | mitigate | Ids are sanitized to `n{i}` for the diagram's own identifiers and the real id appears only inside a quoted, escaped label, following `FlowVisualizer`'s escaping; the inspector page (28-15) additionally HTML-escapes the embedded payload. |
| T-28-07-02 | Information disclosure | Exported diagrams carrying prompt or state content | low | mitigate | `GraphShape` carries ids, kinds, flags and condition KINDS only — never prompts, templates or state values. |
| T-28-07-03 | Repudiation | A silent rendering change slipping past review | low | mitigate | Ten committed goldens make every rendering change a visible diff; the bless path is explicit and named in the failure message. |
</threat_model>
