<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Scenario glob → filesystem | A caller-supplied glob pattern selects files the harness reads and, with `--bless`, writes beside. |
| Live mode → external LLM providers with real API keys | A test harness can be made to spend credits and send fixture prompts to a third party. |
| Registered constructor name → host registry | A scenario names Rust code the harness will run. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-12-01 | Elevation of privilege | Live mode running unintentionally and spending credits | high | mitigate | Three independent gates — flag, environment variable and provider keys — all required; no workflow sets the variable; `default_test_run_never_enters_live_mode` asserts the scripted-only path. |
| T-28-12-02 | Information disclosure | Fixture prompts sent to a third-party provider in live mode | medium | mitigate | Live mode is opt-in three times over and documented as a pre-release smoke path; ADR-0012 governs the key handling. |
| T-28-12-03 | Tampering | `--bless` writing outside the scenario's directory | medium | mitigate | The snapshot path is derived from the resolved scenario file's own directory and case name, never from a caller-supplied path; path traversal generally is canon — covered by `/gsd-secure-phase` and the manual review — and is not minted as a bespoke prohibition here. |
| T-28-12-04 | Elevation of privilege | A scenario naming an arbitrary constructor | medium | mitigate | `registered` targets resolve only against names the HOST registered in Rust; an unknown name is a clear error listing the registered set, never a dynamic load. |
| T-28-12-05 | Repudiation | A flaky scenario passing on a lucky run | medium | mitigate | `--repeat N` treats any divergence across repeats as a failure and names the diverging `seq` range, rather than reporting a pass rate and exiting zero. |
</threat_model>
