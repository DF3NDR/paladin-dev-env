initialize entry point with a theme selected from the operating system's colour-scheme preference.

`28-UI-SPEC.md` is the binding design contract: the spacing scale, the two type weights and four

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → the dev-ui route | An external request reaches operator-grade information about run structure. |
| `InspectorView` JSON → HTML document | Server-side data is embedded into markup a browser parses. |
| Operator browser → the configured Mermaid CDN | The page loads and executes third-party JavaScript at runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-15-01 | Information disclosure | Run structure and field names reachable without admin | high | mitigate | The route is mounted under the same authentication and admin-scope layers the existing admin routes use, and is compiled out of any build without the feature; both are asserted by tests. |
| T-28-15-02 | Tampering | Script-element breakout through the embedded payload | high | mitigate | The serialized view has the script-terminating and comment-opening sequences escaped before substitution, asserted by a test using a view containing both. |
| T-28-15-03 | Information disclosure | Field VALUES rendered on the page | high | mitigate | The view carries names only by type (28-14), the page has no values-shown mode, and the prohibition above states the rule. |
| T-28-15-04 | Tampering | Third-party JavaScript from the configured CDN | medium | accept | Mermaid is loaded at runtime from an operator-configured URL in an admin-authenticated operator's own browser, against a page whose only embedded data is that operator's own view; vendoring a multi-megabyte asset into a published crate was explicitly rejected, and air-gapped operators point the URL at a local mirror. Recorded as an accepted, documented supply-chain exposure. |
| T-28-15-05 | Information disclosure | The dev tool leaking into the published API surface | medium | mitigate | No OpenAPI path attribute and the controller is not one of the drift-guard's three router sources; the committed document is asserted byte-identical with the feature enabled. |
| T-28-15-06 | Denial of service | A very large view producing an unusable page | low | mitigate | Bounded scroll heights on all four panels with no truncation; the whole payload stays in the DOM because the page makes no fetches. |
</threat_model>
