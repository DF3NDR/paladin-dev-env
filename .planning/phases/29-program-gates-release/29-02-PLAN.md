<objective>
Prove the v0.10 HTTP surface did not change under the six paths a v0.9 client already calls. A
whole-document diff would be useless here — v0.10 adds seventeen paths — so the test restricts both
documents to the v0.9 path set, follows the transitive `$ref` closure of those operations into
`components.schemas`, keeps `components.securitySchemes`, drops `info.version`, and asserts deep
equality with a readable diff.

Purpose: SHIP-02's second half, per D-08. `MIGRATION.md` §9.6 currently points at "a golden diff" as
a future artefact; plan 29-05 rewrites that pointer to cite this test by file name.

Output: a frozen `v0.9.0` OpenAPI baseline with checkable provenance and a `paladin-web` integration
test that is gated on every PR by the existing per-crate CI matrix.

This plan leads with a `type="tracer"` task by design: the thinnest end-to-end slice here is
generator to path restriction to frozen-baseline comparison, which touches every layer this plan
modifies and carries a real runnable check. The second task expands the restriction to the `$ref`
closure and the security schemes.
</objective>
