clean commit — the same shape PR #50 used for v0.9.0.

Output: a release-ready commit and `29-CI-EVIDENCE.md`.

This plan has no `type="tracer"` task: it is release mechanics over already-proven artefacts. The tracer
for this phase is plan 29-01's boot test.

lockfile, the OpenAPI baseline and twelve changelogs; reverting it is one revert commit, but every
dependent artefact has to move together. No `checkpoint:decision` is inserted: the v0.9.0 precedent
(bump in the PR, tag on the merge commit) is the recorded house pattern and SHIP-04 requires the semver
and MSRV jobs to be green *in the PR's CI*, which is only possible if the bump lands here.
