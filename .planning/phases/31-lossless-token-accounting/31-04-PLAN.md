<objective>
Finish ACCT-03: give Anthropic's event-accumulation stream and Gemini's cumulative-per-frame stream
the same terminal-chunk usage the OpenAI family now reports, correct Anthropic's cache-exclusive
`prompt_tokens` to the billed figure, and prove parity for every adapter through one shared
conformance case plus the provider-page documentation for the one genuine exception (D-14, D-15,
D-16, D-19, D-20).

Purpose: a parity guarantee that holds for three adapters and not the other seven is not a
guarantee. The shared case is what makes "every adapter's `execute_stream` path is audited"
(ACCT-03) checkable rather than asserted, and the provider matrix is where a user learns which
adapters cannot promise it.

Output: Anthropic and Gemini streaming usage, a ninth conformance case instantiated across the
adapter set, and the provider-page feature matrix row.
</objective>
