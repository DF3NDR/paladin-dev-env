<objective>
Make the prompt/completion/cache/reasoning breakdown observable end to end in both JSON and
Markdown herald output, bring the CLI formatters onto the split, and update every mdBook page and
rustdoc example that still shows a bare token count (ACCT-04; D-21, D-22, D-23, D-29).

Purpose: ACCT-04 is the requirement that makes the rest of the phase *checkable by a human*. A
carrier that is lossless but invisible cannot be verified during UAT, and the JSON herald's stable
key set is what a downstream consumer (and Milestone 14's Treasurer) reads.

Output: heralds and CLI that render the full usage, and a documentation tree with no stale
bare-count example.

The spec-less edge probe could not classify ACCT-04's edge category. Recorded here explicitly
rather than silently dropped: **the complete edge set for ACCT-04 is assumed to be (1) JSON key-set

of unreported rows.** Each is covered by a herald unit test in task 1 and task 2. If a reviewer
identifies a third ACCT-04 edge (for example, how a battalion with zero Paladins renders), it is
not covered by this plan and should be raised before the phase seals.
