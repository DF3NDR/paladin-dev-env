<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository -> published book (`docs/book/html/`) | Anything written into `docs/src` is published |
| local shell -> documentation | `--help` output captured from a locally built binary is pasted verbatim into a published page |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-35-11 | Information Disclosure | the five captured `--help` blocks | medium | mitigate | `--help` output can echo environment-derived defaults. Each capture is read before pasting and any value that is not a literal clap default is replaced with a placeholder; no captured block may contain an API key, a token, a real endpoint host or a local absolute path outside the repository |
| T-35-12 | Spoofing | fabricated flags and environment variables on the CLI pages | medium | mitigate | D-14 deletes rather than annotates every flag and variable the binary does not expose, so a reader cannot be induced to export an invented variable or pass an invented flag believing the documentation; the acceptance criteria assert each fabricated name is absent |
| T-35-SC | Tampering | npm/pip/cargo installs | low | accept | No registry package is installed: the plan builds an existing workspace binary with an existing feature flag and edits prose only |
</threat_model>
