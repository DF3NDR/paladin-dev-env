<objective>
Record the one piece of evidence this environment cannot produce on its own: a real continuous
integration run proving the required check this phase added actually passes on the branch.

Decisions honoured: D-12 (the new lint-job step is a change to a required check, so the phase follows
the pattern two prior phases set — a real run on the pushed branch, recorded with job, run identifier
and step result, before the phase is verified), D-25 (the local gate figures this file compares
against were captured on the closing commit by the previous plan), D-28 (`docs(36.1):` subject).

Purpose: every other gate in this phase was measured locally. The lint job is not local: it is the
check that will block a future pull request, and a local green says nothing about whether the step
was spelled correctly in the workflow, whether the runner has the script, or whether the job's
existing steps still pass beside it. Only a real run answers that.

Output: a seeded evidence file with the local figures and a pending run table, and a blocking
checkpoint that ends with a recorded, observed run.
</objective>
