## Why this file exists

Plan 36.1-11 added a new step to the CI `lint` job (`Code Quality`): `Check public-API `# Examples`
headings`, running `./scripts/check-public-api-examples.sh` in gate mode. The `lint` job is a
required check. Per D-12 (this phase) and the pattern two prior phases set (`33-CI-EVIDENCE.md`,
`36-CI-EVIDENCE.md`), a local measurement is not evidence that this step passes on the runner: it
says nothing about whether the step was spelled correctly in the workflow, whether the runner
resolves the script and its dependencies, or whether the job's pre-existing steps still pass
beside the new one. Only a real, observed run on the pushed branch answers that. This file is
seeded with the local closing-gate figures below and a run table whose cells are `pending` until a
real run is read and recorded — per this plan's own prohibitions, no cell is pre-filled or guessed.
