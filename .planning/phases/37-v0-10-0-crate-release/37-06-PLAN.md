<objective>
Do the one outward-facing act D-01 assigns to the agent — push the branch and open the release PR
— then stop with a written resume condition.

Purpose: the push is what unlocks SC2. The 82 % workspace line-coverage floor is measured only by
CI's `coverage` job (D-00e: this devcontainer has no Docker), and that job only runs once the
branch is on `origin` with a PR open. This plan gets the branch and the PR in place, records the
run IDs that appear, and hands the waiting back to a human rather than parking a watcher.
Output: a pushed branch, an open PR to `main`, opening CI-run table rows, and the D-12 pause
hand-off pair.

What this plan deliberately does not do: merge, tag, tick anything, or wait. `ci.yml` takes
roughly 60-90 minutes on this repository; D-12 makes waiting a hard stop with a resume file.

Governing constraints: sequential execution on the main checkout with hooks ON; the phase
prohibitions P1-P5 in `37-01-PLAN.md` apply. Every `gh` write in this plan has the same fallback:
if the token lacks the permission, record the exact error and hand the exact command to the
maintainer — never retry down a different credential path.
</objective>
