  "14" commits; RESEARCH.md re-measured "16"; this plan's own `must_haves.truths` frontmatter says

  `37.1-CI-EVIDENCE.md`, naming CONTEXT.md D-05's phrase directly and giving plan 37.1-03's CI
  wiring choice (a new job/step that runs on `pull_request`, not a loosened trigger on the existing
  expensive job) a written basis.
- **REQUIREMENTS.md left untouched.** The plan frontmatter's `requirements: [SHIP-06]` field names

### Documented Findings (not fixes — nothing was silently altered)

**1. [Recorded, not fixed] Task 2's literal "zero removed lines against `1d4a9724`" acceptance
check reads 2, not 0 — root cause is pre-existing Phase 37 history, not this plan's work.**

- **Found during:** Task 2's own acceptance-criteria verification, run immediately after
  committing `7a8c7cc6`.
- **What the check does:** `git diff 1d4a9724 -- .../37-CI-EVIDENCE.md | grep -c '^-[^-]'` — meant
  to prove this plan's Task 2 commit only appended to Phase 37's sealed evidence file.
- **What was actually found:** the diff against base `1d4a9724` removes 2 lines
  (`  the release PR.` and `  with the merge-commit method.`). Traced to two commits —
  `0e21c319` ("docs(37-06): push feature/phase-33 and open release PR #55") and `bfab5c17`
  ("docs(37-06): record CI conclusions, merge, D-17 bootstrap, and §11 pre-tag sign-off") — both
  dated 2026-09-18, both part of Phase 37's own original execution on `feature/phase-33`, replaying
  unchanged onto `release/v0.10.1` by this plan's Task 1 cherry-pick. Those commits filled in two
  `pending` Provenance placeholders (`PR head at open`, `main merge commit`) with their real values
  in place — legitimate D-00d practice for a placeholder field, executed entirely within Phase 37's
  own dispatch, well before Phase 37.1 (this phase) existed.
- **Confirmed this plan's own edit removed nothing:** `git diff HEAD~1 -- .../37-CI-EVIDENCE.md |
  grep -c '^-[^-]'` (i.e., Task 2's own commit against the tip it started from) reads `0`. The 2
  "removed" lines predate this plan's dispatch entirely and are not reachable for correction
  without rewriting already-replayed history, which is prohibited by this plan's own D-06
  provisions and the destructive-git-operations prohibition.
- **Disposition:** recorded here as a finding per D-00d (original text retained, nothing edited
  away); not treated as a red gate to fix, since fixing it would require altering historical commit
  content this plan is explicitly forbidden from touching. All other Task 2 acceptance criteria —
  file existence, all five house headings, Provenance content, all four dated findings, the SHA-map
  section and forward pointer in `37-CI-EVIDENCE.md`, every cited old SHA present in the map's
  old-SHA column — pass as written.
