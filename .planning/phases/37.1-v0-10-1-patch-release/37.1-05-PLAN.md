<objective>
Remove the race that killed the `v0.10.0` release run before it ever reached the publish step, and
leave behind a test that would have caught it.

Purpose: the release script captured a full response into a variable and then re-piped that
variable through a reader that exits as soon as it has the first line. Under `pipefail` with
`errexit`, a large enough body means the writer's next write lands on a closed pipe and the script
aborts with the signal-driven status. The chosen fix is not a tuning of that race: bash can slice
the first line of a variable with parameter expansion, which removes the subprocess and the pipe
entirely, so the whole failure class has nothing left to act on.
Output: the fixed extraction, a committed regression assertion with a 200 000-character body, and
a recorded sweep naming three further instances of the same shape that this phase deliberately
does not fix.

Governing constraints: D-08 stage 1 — the build wave; red is expected and is fixed inside the six
success criteria. D-00d — the sweep results are recorded, never fixed silently.
</objective>
