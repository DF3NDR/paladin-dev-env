<objective>
Prove the sign-off actually happened, on the remote, before anything irreversible is put in front
of anyone.

Purpose: the previous release's sign-off was given in session and the merge happened first; that
was recorded as a process deviation. This phase makes the order structural. The agent reads the box
from the remote branch at the pull request's head — not from its own working tree — and if the tick
is not there, the phase stops. Then the checks on that true final commit, the one the merge will
carry, are waited for as a hard stop.
Output: a verified tick on the remote, recorded with the tick commit's SHA and author, and a second
resume file.

**This plan is not autonomous.** It carries a conditional stop on a missing tick and ends in a hard
stop.

Governing constraints: D-10 (the fixed order and its structural enforcement), D-00a (only the
maintainer ticks), D-00i (waiting is a hard stop with a resume file).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local working tree → the remote branch's content | A tick that exists only locally satisfies a working-tree check and gates nothing; the reading must come from the remote |
| the signed-off commit → the commit the merge carries | A tick buried under later commits means the merge carries a tree nobody signed off |
| agent commits → sign-off state | The agent writes in the same file the box lives in; proving it never changed the box's state requires inspecting its own diffs, not trusting its intent |

## STRIDE Threat Register (ASVS L1; block on `high`)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-37.1-41 | Spoofing | A local-only or forged tick | high | mitigate | The box is read from the file's content at the resolved remote commit; the ticked-box count is required to have increased by exactly one against the base commit; the tick commit's author is recorded and asserted not to be the agent. |
| T-37.1-42 | Elevation of Privilege | The merge carrying a commit that was never signed off | high | mitigate | The tick commit is asserted to be the tip of the remote branch, and this plan deliberately adds no commit to that branch — the resume file is left uncommitted for the close-out branch to carry. |
| T-37.1-43 | Repudiation | An agent commit silently changing a box's state | high | mitigate | Task 1 inspects this phase's own commits against the audit file and asserts none changed a box's state; a prohibition forbids amending or rewriting the tick commit. |
