<objective>
Land the record on the default branch the same way everything else does — through a reviewed pull
request — and stop at ready-to-close.

Purpose: the default branch is protected, and the post-tag record is exactly the kind of thing that
gets pushed around a ruleset "just this once". It does not here. The record goes through a small
documentation-only pull request, and the phase ends by handing the maintainer a list of what is
already true and what the milestone-close command will check, rather than running that command
itself.
Output: the ready-to-close hand-off, the pushed close-out branch, its pull request, and a blocking
checkpoint at the merge.

**This plan is not autonomous.** It ends at a blocking human-action checkpoint.

Governing constraints: D-12 (the close-out branch and its pull request; the phase ends at
ready-to-close), D-00b (the maintainer merges).
</objective>
