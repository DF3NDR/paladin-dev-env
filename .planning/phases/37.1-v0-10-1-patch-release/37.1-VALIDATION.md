## Sampling Rate

- **After every task commit:** Run the relevant single-file shell test (`./tests/scripts/create-or-reuse-release_test.sh` or the new `./tests/scripts/check-publish-order_test.sh`), plus `cargo package -p paladin-battalion --no-verify` for SC1 tasks
- **After every plan wave:** Run `make test-shell-guards && make check-gates && make release-check`
- **Before `/gsd-verify-work`:** Full suite must be green
- **Phase gate (re-seal, D-09/D-10):** the full eight-row `## 13.` table, all locally runnable except the CI-only 82% coverage floor (D-00e — no Docker in this devcontainer), before the maintainer ticks §13
- **Max feedback latency:** 30 seconds for the quick command
