<objective>
Give operators the `treasurer:` price table (PRICE-01) and install the pricing decorator on both
production run paths (PRICE-03 wiring), so a configured price reaches every LLM call made by
`paladin-server`'s agent host, its runtime-provisioned agents and its run engine.

Purpose: 38-02 proved the path with a hand-built `PriceTable`; this plan makes the table
operator-configured, validated at boot with precise errors (ROADMAP success criterion 1), inert
when omitted, and wired at the two `LlmProviderFactory::create` call sites the research verified
(RESEARCH Pattern 3, Open Question 1's recommendation: wrap at the facade call sites, not inside
the factory).

Output: `src/config/treasurer.rs`, `Settings.treasurer`, the `config.example.yml` section, boot
validation in `paladin-server`, and pricing installed in `build_agent` and
`paladin_port_from_settings`.

**Discretion choices recorded (CONTEXT.md "Claude's Discretion"):** (1) a hand-rolled exact
decimal parser instead of `rust_decimal` — the grammar is deliberately narrow (unsigned digits
with an optional 1-9 digit fraction), exact integer arithmetic is simple to prove with the edge
tests below, and it keeps the dependency count flat (no new crate, so no `Cargo.lock`, `deny`,
`audit` or MSRV change and no package-legitimacy checkpoint); (2) only `treasurer.currency` has an
env override (`APP_TREASURER_CURRENCY`); the map-shaped `pricing` field is config-file only,
mirroring `ToolCallLimitConfig.per_tool` (RESEARCH assumption A2); (3) an empty table skips
installing the decorator (`with_pricing` returns the inner port).

**Flagged assumption (surfaced, not silently dropped):** the legacy CLI commands
(`paladin-cli agent`, `battalion`) build their own `LlmPort` from per-agent YAML, not from
`Settings`, and are not priced in this phase — their costs stay `None` with no pricing warning.
Both run paths D-09 names (engine and agent loop, as served by `paladin-server`) are priced. CLI
spend surfaces belong to Phase 39 (LEDGR-04).

**Reversibility:** D-01 (per-1M unit) and D-07 (the `treasurer:` section name) are rated costly —
operator-facing config and docs would need rewriting after release. Flagged, not gated.
</objective>
