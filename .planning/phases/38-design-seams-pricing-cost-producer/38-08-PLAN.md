<objective>
Give the engine path its real `ExecutionMetadata` producer (D-12): build the metadata from each
run's `RunFinished` event (model, usage, cost, duration) and hand it to `Herald::finalize_stream`,
wired into the production run worker whenever the operator configures a herald.

Purpose: 38-02 gave the agent loop its producer; this closes ROADMAP success criterion 3 on the
primary run path — a completed engine run's `ExecutionMetadata.cost_estimate` carries the currency
cost end-to-end, or `None` when unpriced. A `TraceSink` is the seam that sees `RunFinished` in
production (the worker already composes one sink fan-out per run), and building the metadata from
the event keeps the engine crate itself free of any herald dependency.

Output: `ExecutionMetadata::from_run_finished`, `HeraldTraceSink`, `RunWorkerPool::with_herald`,
the `build_run_api` wiring, and an end-to-end engine test from price table to herald text.

**Tracer:** expansion of plan 38-02's tracer.
</objective>
