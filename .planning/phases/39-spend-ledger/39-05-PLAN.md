<objective>
Fill the ledger on the agent loop: one settlement per priced model call inside
`PaladinExecutionService` (D-08), keyed per D-07, installed on HTTP agent services and — for Platform
API runs of agent-kind assistants — on the run engine's shared service in a mode that can never
double-count engine nodes.

Purpose: LEDGR-04 needs spend from both production run paths; D-07 names the agent-loop key
(`run_id` = Platform API run id when present, else the execution id; superstep = call ordinal;
attempt = 1). RESEARCH Open Question 2 is resolved by carrying the Platform run id in `RunScope`
(which was designed to gain a run id) rather than a half-wired parameter.

Output: `AgentLoopSettlement`, `with_treasury_ledger`, `RunScope::with_run_id`, and the ledger
threaded through `agent_host.rs`/`facade_provisioner.rs`.
</objective>
