<objective>
Expand the tracer's single-run gate to the list: `GET /v1/runs` returns only the caller's tenant's
runs (or every run for an Admin), with the filter living inside each adapter's SQL so the keyset
cursor stays correct, and bring the in-memory and PostgreSQL adapters to attribution parity with
SQLite under one shared contract suite.

Purpose: PLAT-07 names `GET /runs` explicitly, and D-12's list mechanism is the half of the shared
authorization function that must not be a post-filter. TENANT-02 needs the attribution guarantees
(null for no principal, immutable after insert, single-statement write) proven on every backend.

Output: `RunQuery.scope`; scoped `list` on three adapters; six contract clauses; Postgres
attribution columns; scoped `list_runs`; a facade end-to-end over on-disk SQLite.
</objective>
