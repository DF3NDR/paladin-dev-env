## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client -> agent execute / stream / jobs | authenticated principal starting LLM spend outside the run pipeline |
| HTTP client -> `POST /v1/threads/{id}/fork` | a new run created from an existing thread |

| T-41-19 | Elevation of Privilege | Admin as an unbounded spend path | high | mitigate | Treasurer receives `RunAttribution` only; `admin_principal_is_bound_by_its_allowance` |
