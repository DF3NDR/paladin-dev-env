<objective>
Prove Phase 42's engine-path halt end-to-end on its thinnest real path, then register what that
path adds.

This is the phase's tracer (TRACER_MODE). It runs one allowance-bound graph run through every layer
the engine halt touches: operator config (`TreasurerConfig`) -> `AllowancePolicy` -> `Treasurer`
(the shared ceiling evaluation and the new `TreasurerSpendGuard`) -> the new `SpendGuard` output port
(`paladin-ports`) -> the `WarEngine` top-of-loop boundary check (`paladin-battalion`) writing the same
`WaypointStatus::Halted` Waypoint the cancel path writes -> `RunOutcome::Halted { cause }` -> the
worker's `map_outcome` -> the run row through the real SQLite run repository -> `GET /v1/runs/{id}`
answering `halted`. Task 1 lands the core type, the port and the engine mechanism and stops at its
own green gate (engine tests plus a workspace-wide `cargo check`), because the `RunOutcome::Halted`
field change breaks every pattern that names the variant's fields; Task 2 lands the policy, the
worker and the wiring and finishes with the end-to-end tracer test; Task 3 registers the surface.

Purpose: if an exhausted allowance cannot halt a running graph through config -> Treasurer -> port ->
engine -> worker -> HTTP without an architectural change, every later plan is wasted. The tracer is
production code.

Output: `HaltReason` (core), `SpendGuard` (ports), `HaltCause` and the boundary check (engine),
`Treasurer::evaluate` and `TreasurerSpendGuard` (facade), `RunWorkerPool::with_treasurer`, the
reordered `build_run_api`, and `engine_spend_halt_tracer`.

**Expansion owners (not deferrals):** the persisted `halt_reason` column, the `GET /runs` fields and
the caller webhook key land in 42-03; fail-closed, every-boundary, no-ceiling, sticky child halts
and resume-by-fork in 42-04; `RunFinished.halt_reason` and the SSE `done` reason in 42-05;
`RunFinishStatus::Cancelled`, the per-run cancel probe and the drain rule in 42-06; the derived agent
budget and the HTTP agent routes in 42-07/42-08 and the worker agent-kind path in 42-09; notices in
42-10/42-11.
