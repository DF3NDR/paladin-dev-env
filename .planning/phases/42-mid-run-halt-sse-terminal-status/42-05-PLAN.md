<objective>
Make the SSE terminal event say why a run halted, identically on every stream path.

Task 1 adds `halt_reason` to the engine's own `RunFinished` trace event (the reason is correct at the
source, D-05) -- a field addition the compiler forces through every construction site in the
workspace -- and proves stored `run_traces` rows still read back. Task 2 renders the reason on the
live `done` (`map_trace_event`), the degraded `done` (`terminal_payload`) and the replay path
(`replay_stream`, now row-trusting, G10) through the one `wire_json` builder, with stream tests
proving the three agree. Task 3 registers and documents the `done` change.

Purpose: PLAT-09's "the SSE `done` event matches the persisted status -- `Halted` with the Treasurer
reason for a spend halt" (ROADMAP success criterion 4), on both the live and the degraded stream
paths (D-14, D-16). The `cancelled` half and the drain rule are 42-06.

Output: `RunFinished.halt_reason`, `run_finish_status` returning the reason, `done.halt_reason` on
three paths, the run-trace legacy clause, stream agreement tests, registers and docs.
</objective>
