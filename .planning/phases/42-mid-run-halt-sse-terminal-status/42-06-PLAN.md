<objective>
Make the SSE terminal event say `cancelled` when a caller cancelled the run, and say nothing
terminal when the worker merely drained it.

Task 1 adds `RunFinishStatus::Cancelled` (and `#[non_exhaustive]`), maps the engine's
`CancelRequested` cause to it, and gives every per-run engine a `PerRunCancelProbe` so a same-instance
cancel -- which today only fires the in-process child token, indistinguishable from a shutdown --
reaches the engine as a caller cancel (G1). Task 2 suppresses the drain's reasonless `RunFinished` at
the bus sink (D-15, G1c), proves both cancel routes and the drain end to end, adds the phase's
assumption-delta invariant test, and registers the change.

Purpose: PLAT-09's "`Cancelled` for a caller-cancelled run" and D-15's "nobody ever sees `halted`
for a run that is still `Running`".

Output: `RunFinishStatus::Cancelled`, `PerRunCancelProbe`, the cause-aware mid-superstep halt,
`RunEventBusSink::with_shutdown_token`, cancel/drain stream tests, the invariant test, registers.
</objective>
