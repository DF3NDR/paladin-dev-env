<objective>
Give the operator-notice path a halt rung: the Phase 41 once-per-window notice store learns a notice
kind (migration 014), and the durable operator webhook learns an `allowance_halted` event signed
with the operator secret -- the storage and delivery legs D-18's halt notice travels on.

Split from the original 42-09 at plan-check revision 1 (scope_sanity), as the checker proposed
(storage + webhook here, guard + end to end in 42-11). Task 1 adds the halt rung to the notice store
(migration 014, `NoticeKind`, the rebuilt dedup index, the arbiter lists and contract clauses). Task 2
adds the `allowance_halted` operator event to the durable webhook path (event kind, adapters' parse,
operator signing branch, payload). Task 3 registers the surface and the schema change.

Purpose: D-18 ("a spend halt notifies the operator once per window") needs a store identity that
keeps a halt distinct from a warning and an event the operator can receive; 42-11 makes the boundary
guard use both.

Output: migration 014, `NoticeKind`, `RunEventKind::AllowanceHalted`, the operator signing branch,
contract clauses, registers.
</objective>
