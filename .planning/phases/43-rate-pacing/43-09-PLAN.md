Finish the operator surface and close every server composition root: the `redis` backend and env
overrides on `treasurer.cadence` (D-10), `build_cadence` producing the resilient Redis composite,

worker run wiring); the CLI's one-shot commands (`paladin-cli`) build ports outside that set and are
not changed here. `WarEngine` stampede-lock wiring is a library builder (43-11); the server attaches
no node cache today, so it attaches no lock either.

the shared boot wiring, docs, the registered surface.
