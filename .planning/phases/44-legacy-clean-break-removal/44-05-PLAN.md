Implements D-01, D-02, D-03 (Phalanx surfacing), D-05 and D-07 for Phalanx.

**Entry points.** `execute`: delete the whole-run `timeout` wrapper; call `phalanx.config().validate_aegis()?`, then `self.execute_internal(phalanx, input, &None).await`. `execute_with_cancellation`: delete its timeout; validate, then `tokio::select!` between `self.execute_internal(phalanx, input, &Some(cancellation_token.clone()))` and `cancellation_token.cancelled()` (still returning `BattalionError::Cancelled`). **Typed collection.** Give `execute_internal` a `cancel: &Option<CancellationToken>` parameter. Change `execute_collect_all`, `execute_first_success` and `execute_majority` to return `Result<(Vec<(String, PaladinResult)>, Vec<AttemptFailure>), BattalionError>`, each successful result paired with its Paladin's name. In `execute_collect_all`, each spawned task owns a clone of the port, the Paladin, the input, `phalanx.config().aegis` and the token; it acquires its permit (map a closed-semaphore error to `AttemptFailure::from_error(name, 1, PaladinError::ExecutionError(..))` instead of `unwrap`) and holds it across `run_with_aegis(..)`; await the join handles in declaration order so both vectors follow declaration order; a `JoinError` becomes `AttemptFailure::from_error(name, 1, PaladinError::ExecutionError(format!("Task join error: {e}")))`. `execute_first_success` runs `run_with_aegis` inside each boxed future and keeps today's all-fail message `All Paladins failed: {last failure's error}`. `execute_majority` consumes `execute_collect_all` and replaces its two `unwrap()` calls with non-panicking lookups (a missing entry becomes `BattalionError::ExecutionError`).

**`execute_internal` failure handling.** If failures exist, match `&config.aegis.on_error`: `None` -> return `BattalionError::AggregationError(format!("Phalanx execution failed with {n} errors: {joined}"))` where `joined` is each failure's `node_error` display separated by `; `; `Some(ErrorHandlerSpec::Absorb { .. })` -> `warn!` and continue; any other value -> `BattalionError::ValidationError` naming the handler. **Removals.** Drop the `tokio::time::{Duration, timeout}` import and the legacy `ErrorStrategy` import; update the struct and `execute` rustdoc that mention timeouts and error strategies.
