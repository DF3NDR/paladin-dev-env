- `NodeId` is `#[serde(transparent)]` over a `String`; `Transience` serializes as `"Transient" | "Permanent" | "Unknown"`.
- From 44-04 / 44-05: Formation's Absorb branch and Phalanx's failure collection already hold each `AttemptFailure { error, node_error }` and build the v0.10 summary from it in exactly one place each.

  <context>
D-06 (operator decision, discuss-phase 2026-10-09) retypes `node_errors` to the structured `node_error::NodeError` and is rated **one-way**: `BattalionResult` is a serialized value (JSON herald output, the CLI formatter, exported metadata, any stored result). The operator chose the retype; CONTEXT left to the planner (Claude's discretion) the Paladin-name -> `NodeId` mapping and the `NodeErrorSource` used for a Paladin failure, and research added a consequence the discussion did not cover: a v0.10 document with a non-empty `node_errors` stops deserializing. Those are what this gate confirms. Undoing them after release means another breaking change to every stored result and every reader of the JSON herald.

Proposed element (serde, externally tagged): `{"node_id": "<Paladin name>", "attempt": <the attempt that produced the final failure, 1-indexed>, "transience": "Transient" | "Permanent" | "Unknown", "source": <one of>}` where `source` is `{"Llm": {"kind": "LlmFailure", "status": <u16 or null>, "provider": <string or null>, "message": "<redacted display>"}}` for an LLM-provider failure, `{"Paladin": {"kind": "<PaladinError variant name>", "status": null, "provider": null, "message": "<display>"}}` for any other Paladin failure, and `{"Timeout": "Run"}` / `{"Timeout": "Idle"}` for a per-attempt timeout. Example: `{"node_id":"Skirmisher","attempt":2,"transience":"Unknown","source":{"Paladin":{"kind":"ExecutionError","status":null,"provider":null,"message":"Execution error: Skirmisher failed"}}}`. Deserialization is strict: a v0.10 element `{"node_name": .., "error": ..}` is rejected; an empty or absent `node_errors` still reads; no compatibility deserializer (D-00c). Herald lines: Markdown field `<node id>` = `attempt <n>, <transience>: <source display>`; Table `  <node id> (attempt <n>, <transience>): <source display>`.
  </context>
