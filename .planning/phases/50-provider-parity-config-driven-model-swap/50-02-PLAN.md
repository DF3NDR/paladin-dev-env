<objective>
Record the policy and land the contract every later Phase 50 plan builds on: ADR-0061 (amending
ADR-0004) states how a configured sampling parameter the target provider/model cannot honour is
handled (refuse explicit, omit auto visibly), and `paladin-ports` gains the additive `ModelProfile`
port type and the defaulted `LlmPort::model_profile` method; the three decorators forward it so the
policy cannot be silently bypassed in the composed production stack.

Purpose: PARITY-02 and handoff D-1 settled at discuss (D-01..D-04a); ADR-0004's provider-aware,
no-undiscoverable-substitution principle is extended, not weakened (D-00f). The ADR comes first as the
phase's licence for the policy (the ADR-0059/0060 "licence plan" precedent), and the type is
interface-first: plans 50-03, 50-05, 50-06, 50-14 and Phase 51 implement against it. Phase 51 adds
effort levels and budget bounds to the same `#[non_exhaustive]` type (D-00j), so construction is only
through `new()` + `with_*`.

Output: ADR-0061, the ADR-0004 note, PROMOTION.md at 0062, a PROJECT.md row; `model_profile.rs`; the
trait method; three decorator overrides; refreshed API baseline and CHANGELOG entries.
