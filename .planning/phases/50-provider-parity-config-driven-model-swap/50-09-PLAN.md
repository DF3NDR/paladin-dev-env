<objective>
Make the `llm.<provider>` blocks live through one public library API: the provider block gains the
PARITY-03 knobs and per-model overrides, one layering function applies D-13's precedence (agent > block >
legacy env > compiled default, 300 s for reasoning models, `${VAR}` placeholders), the bridges in
`config/bridge.rs` become the per-provider `from_layers`, and `LlmProviderFactory::create_from_config`
builds any of the nine adapters from configuration, naming provider and model on every error.

Purpose: PARITY-03 (B-2: blocks parsed but inert, factory env-only, bridges with no production caller);
D-12, D-13, D-06; RESEARCH Pattern 3 (injected env; `set_var` is `unsafe` in edition 2024 and `paladin-llm`
denies `unsafe_code`), Pitfall 8 (placeholders arrive literally; availability is env-based), Open Question 6
(key resolution). Composition roots move onto this API in plan 50-10.

Output: extended `LlmProviderConfig`, `config/layers.rs`, per-provider `from_layers`, `create_from_config`,
`is_configured`, migrated literal sites, tests, baseline and changelog entries.
</objective>
