50-05 behind the operator: this plan sits in wave 3 beside 50-05 and blocks only plan 50-06, which genuinely
needs the transcript. A quota-exhaustion error cannot be provoked on demand (A2-50-04), so whether SC-5's
usage-cap clause may stand as recorded best-effort for a vendor with no captured body is the owner's call, asked
here per vendor (R-2) instead of being assumed in plan 50-13. Its dependencies (50-02 for ADR-0061's
`## Owner readings`, 50-04 for the harness) would allow wave 2; it is placed in wave 3 on purpose, so the
operator's run never gates plan 50-05.

Output: `50-SEED-PROBE.md` with its R-2 usage-cap list, and ADR-0061's R-2 row filled in.
</objective>
