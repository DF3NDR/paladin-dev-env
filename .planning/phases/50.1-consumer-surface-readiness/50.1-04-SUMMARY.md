# Phase 50.1 Plan 04: Gemini, Qwen, Grok and Kimi `new(api_key, model)` Summary

**`GeminiConfig`, `QwenConfig`, `GrokConfig` and `KimiConfig` now construct with `new(api_key, model)` (endpoint defaulted from their `*_DEFAULT_BASE_URL` constants, replaced with `with_base_url`), with all 87 in-tree call sites migrated, each break measured as `method_parameter_count_changed` and registered, in three commits: `1cc3b0da` (Gemini tracer), `ed88ea5a` (Qwen and Grok), `06eeec98` (Kimi).**

## Accomplishments

- Four constructors changed with rustdoc naming the key parameter ("never a URL") and an `# Examples` doctest each (`new(key, <DEFAULT_MODEL>)` plus `with_timeout_seconds`): `GeminiConfig::new (line 343)`, `QwenConfig::new (line 290)`, `GrokConfig::new (line 190)`, `KimiConfig::new (line 199)` all pass. Timeout defaults are unchanged (`default_timeout_seconds(<PROVIDER>, &model, 60)`); every `from_env()` / `from_parts` is untouched.
- Call sites migrated in the same commit as their type, with `.with_base_url(..)` wherever the old call passed a mock-server or non-default URL (and the URL argument simply dropped where it was the type's own default constant): Gemini 5 (2 adapter tests, 2 `lib.rs`, 1 registry), Qwen 17 (14 adapter, 2 `lib.rs`, 1 registry), Grok 21 (18 adapter, 2 `lib.rs`, 1 registry), Kimi 44 (38 adapter, 2 `lib.rs`, 1 registry, 2 `services/commissary.rs`, 1 `pricing.rs`). `config/bridge.rs` needed no change (flagged assumption A1: it builds by literal, `grep 'Config::new(' bridge.rs` finds only `LlmProviderConfig::new`).
- New tests per type: `<p>_config_new_takes_key_and_model_and_defaults_the_endpoint` and `<p>_config_with_base_url_replaces_the_default_endpoint`; the Kimi one also pins `new(k, "kimi-k3").timeout_seconds == 300`. `knob_builders_set_base_url_and_timeout_on_every_config` uses the new shape for all four and passes.
- RED shown before each implementation: Gemini (impl temporarily reverted: `cargo check --tests` gave 8 E0061 errors), Qwen and Grok (migrated sites plus tests against the old signature: 44 E0061), Kimi (47 E0061).
- Register, in each commit: section 9.2 SURFACE-02 row per type, PARITY-03 row and allowlist justification no longer claim `new` is unchanged, DR-19 names `DeepSeekConfig`, `GeminiConfig`, `QwenConfig`, `GrokConfig` and `KimiConfig` after commit 3, root and crate CHANGELOG Breaking Changes entries extended, `crates/paladin-llm/Cargo.toml` lint-table comment updated (no new lint line: `method_parameter_count_changed` was already allowed). `make check-migration-allowlist` exited 0 after every commit.
