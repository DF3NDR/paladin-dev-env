## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| facade public surface -> downstream consumer | new public paths (Aegis family, harmonised `*Config::new`) become a contract the consumer compiles against | API surface (integrity-sensitive) |
| consumer code -> `*Config` builders (`with_base_url`) | a caller-chosen `base_url` decides where the credential header is sent | API keys (secret) |
| `paladin-llm` adapter -> vendor endpoint | credential-bearing HTTPS requests, including the default output ceiling | API keys (secret), user content |
| `*Config` -> logs / panic messages | a `Debug`-formatted config may reach a log line | API keys (secret) |
| register files -> CI `semver` job | suppression lines that silence cargo-semver-checks | lint allowances (integrity-sensitive) |
| GitHub Actions runner -> repository | the new `consumer-surface` job executes workspace code on every push and pull request | CI execution |
| operator machine -> repository | a transcript of credentialed vendor calls becomes a committed file | vendor bodies, possibly echoing request data |
| evidence file -> compiled registry | transcript and dated docs values become shipped per-model limits | vendor facts (integrity-sensitive) |
| MIGRATION.md / consumer guide -> consumer operator | guidance a consumer follows to restore 429 pacing and predict build-time refusals | configuration guidance |
