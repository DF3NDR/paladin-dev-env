## Sampling Rate

- **After every task commit:** the task's own `<automated>` verify (the touched crate's tests, the muster when it changed, `make check-migration-allowlist` for every SURFACE-02 commit), plus `cargo fmt --check` and `cargo clippy --offline -p <crate> --all-targets --all-features -- -D warnings`
- **After every plan wave:** `cargo test --offline --workspace --all-features --no-run`, `make check-gates`, `make api-surface`, `make check-examples`, `make check-api-examples`
- **Before `/gsd-verify-work`:** the plan 50.1-09 Task 3 seal gate set must be green (CI green including the new `consumer-surface` job)
- **Max feedback latency:** the muster (about 1 min warm) is the slowest per-task check; semver measurements (minutes) run only inside SURFACE-02 tasks
