<objective>
Close the first part of verification gap G-2 (51-REVIEW.md CR-01): the agent host's load-time check of a provider
block's default effort resolves the fallback in the same order the adapters do at send time -- the agent's own
`reasoning_fallback` first, the block's second, `Refuse` last -- instead of the inverted `block.fallback.or(def...)`.

Purpose: D-09 promises a build-time answer equal to the send-time answer, with REASON-01's precedence. Today a block
`nearest_lower` with an agent `refuse` loads and then refuses every call, and a block `refuse` with an agent
`nearest_lower` is refused at load although every call would substitute.

Output: a one-expression fix in `check_block_reasoning`, corrected rustdoc, three precedence tests written red-first
and one hint test.
</objective>
