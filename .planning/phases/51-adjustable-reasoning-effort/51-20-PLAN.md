  `PaladinBuilder::build`, by the agent host at load, by a fallback chain's pre-flight, and at send time -- always
  beneath an agent's or a request's own fallback.

  i.e. its step model plus its adapter's own `llm.<provider>.reasoning_effort` / `reasoning_fallback` beneath the
  request's values; a hop whose provider default its model cannot honour refuses the chain before the first call even
  when the request sets no effort (reason `fallback hop <index>: ... (set by \`llm.<provider>.reasoning_effort\`)`);
  a request with no effort over hops that set no default is never refused.

  agent's effort and fallback, so the port's provider-level defaults sit beneath them with the same precedence and
