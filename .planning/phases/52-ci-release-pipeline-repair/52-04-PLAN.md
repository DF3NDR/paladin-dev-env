<objective>
Give `finalize-release-body.sh` the same size guard as the create step. A release body created at the cap plus the
artifact sections finalize appends would otherwise overflow GitHub's limit and turn the tag's `Finalize Release Body`
job red (RESEARCH Pitfall 6). The guard reuses plan 52-02's helper unchanged, truncates only the curated part, and stays
byte-idempotent across re-runs.

Purpose: completes CIREL-05 / D-11 ("`finalize-release-body.sh` ... is given the same guard if it can push a body over
the cap"). Verification posture is D-12's.
Output: the guarded finalize script and its new harness cases.
</objective>
