## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|----------------------|
| Parked watcher or polling | A `gh run watch`, a `sleep` loop or a spawned agent waiting for the runs on `SHA-P` | blocking | The resume condition below is checked once, by the next plan, not by anything running now |
| Re-running a red job to get green | A re-run outside the recorded `named-rerun` rule | blocking | D-00j: record and halt; only F-58-03's named test, once, in push or PR CI |
| Reading an aggregate status | Using the commit status or the PR rollup instead of each run's and each job's own conclusion | high | Read `status` and `conclusion` per run and per job from `actions/runs?head_sha=` and `actions/runs/<id>/jobs` |
| Fixing during the stop | Editing code, versions or the register after `SHA-P` to turn a red green | blocking | Fixes need a new plan; the bump does not start on a red read |
