## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent -> the irreversible acts | Merge, tag, publish and yank are outside the agent's authority |

| Trusted Publishing -> standing credential | The publish authenticates by short-lived OIDC exchange; no credential exists |
