## Decisions Made
- Pre-push (not pre-commit) is the correct gate layer: GSD executor commits run with `--no-verify` (`workflow.worktree_skip_hooks=true`), so a commit-stage hook would never fire for them; pre-push is what actually intercepts the drift before it reaches CI.
- Hook scoped with `files: ^(src|crates)/.*\.rs$|^Cargo\.toml$` rather than `always_run: true`, so a docs-only push does not pay the ~95s `cargo public-api` cost.
- No `CONTRIBUTING.md` created (plan explicitly excluded it, per an existing dangling reference in `.pre-commit-config.yaml`'s header comment).
